# IG.01 - Introduction To Information Gathering

### What is it?
- Same thing as reconnaissance
- First phase of penetration test
    - Gather or collect information about individual, company, website, or system you target
- Learning more about your target helps you be more successful during the later steps of a penetration test
    - All this information adds up
    - Easier to break something that you know
- Two main types:
    - Passive Information Gathering
        - Not interacting with the target
        - Usually does not need authorization
    - Active Information Gathering
        - Actively engaging with the target
        - Always needs authorization

### What Are We Looking For?
- Passive Information Gathering
    - IP addresses
    - DNS information
    - Domain names and domain ownership information
    - Email addresses
    - Social media profiles
    - Web technologies in websites
    - Subdomains
- Active Information Gathering
    - Open ports
    - Internal infrastructure (both of a network and an organization)
    - Enumerating information
