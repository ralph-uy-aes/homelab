# FS.05 - Transport Layer Part 2

### UDP
- Connection-less and lightweight
- Simple way to transmit between devices
- Not as reliable as TCP
- Focuses on simplicity and speed
- Good for real-time applications
    - Music
    - Streaming
    - Gaming
    - VoIP
- UDP packets are independent of previous or future packets

### netstat
- Can let you see active TCP sessions
- Use `-antp` flag to see program name and stuff
- Shows state so you can see when they're active and when they're about to be closed
