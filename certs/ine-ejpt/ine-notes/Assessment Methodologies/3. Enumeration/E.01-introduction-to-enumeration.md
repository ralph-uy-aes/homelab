# E.01 - Introduction to Enumeration

### Enumeration
- After host discovery and port scanning, next phase is service enumeration
- Goal: gather specific/detailed info about hosts and services
- Info includes: account names, shares, misconfigured services, etc.
- Active connections to remote devices

### Protocols
- Many protocols can be targeted if misconfigured or left enabled
- Tools/techniques to interact with these protocols for later exploitation

### Penetration Testing Methodology
- **Information Gathering**
    - Passive Information Gathering (OSINT)
    - Active Information Gathering
        - Network Mapping
        - Host Discovery
        - Port Scanning
        - Service Detection & OS Detection
        - Service & OS Enumeration
- **Enumeration**
    - Service Enumeration
    - User Enumeration
    - Share Enumeration
    - Vulnerability analysis and threat modeling
- **Exploitation (Initial Access)**
    - Vulnerability Analysis
    - Vulnerability Identification
    - Developing/Modifying Exploits
    - Service Exploitation
- **Post-Exploitation**
    - Local Enumeration
    - Privilege Escalation
    - Credential Access
    - Persistence
    - Defense Evasion
    - Lateral Movement
- **Reporting**
    - Report Writing
    - Recommendations
