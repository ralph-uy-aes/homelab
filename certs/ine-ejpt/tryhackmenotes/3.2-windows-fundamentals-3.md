## 🔄 Windows Update
- Microsoft provides security updates, feature enhancements, and patches via Windows Update.
- **Patch Tuesday** – 2nd Tuesday of each month (critical updates can be pushed outside this schedule).
- Located in Settings → Update & Security → Windows Update.
- Alternatively: `control /name Microsoft.WindowsUpdate` in Run or CMD.
- Updates can be postponed but **cannot be ignored indefinitely** in Windows 10/11.

## 🦠 Virus & Threat Protection
- Two sections: **Current threats** and **Virus & threat protection settings**.

### Current Threats
| Feature | Description |
|---------|-------------|
| **Scan options** | Quick scan, Full scan, Custom scan |
| **Last scan** | When the last scan was performed |
| **Quarantined threats** | Isolated threats removed periodically |
| **Allowed threats** | Items identified as threats that you allowed (use with caution) |

### Virus & Threat Protection Settings
| Feature | Description |
|---------|-------------|
| **Real-time protection** | Locates and stops malware from running |
| **Cloud-delivered protection** | Faster protection with cloud data |
| **Automatic sample submission** | Sends samples to Microsoft |
| **Controlled folder access** | Protects folders from unauthorised changes (ransomware protection) |
| **Exclusions** | Skip specific files/folders from scanning (use with caution) |
| **Notifications** | Alerts about device health |

- **Ransomware protection** requires Controlled folder access, which requires Real-time protection.
- **Tip:** Right-click any file/folder → "Scan with Microsoft Defender" for on-demand scans.

## 🔥 Firewall & Network Protection
- Controls what traffic is allowed through ports.
- Three firewall profiles:
  - **Domain** – authenticates to a domain controller.
  - **Private** – user‑assigned for home/private networks.
  - **Public** – default for public networks (Wi‑Fi hotspots, airports, coffee shops).

### Actions
- Turn firewall on/off; block all incoming connections.
- **Allow an app through firewall** – view/edit app permissions per profile.
- **Advanced Settings** (`WF.msc`) – for advanced users (leave defaults unless confident).

## 🔒 Device Security
- **Core isolation** – Memory integrity prevents malicious code insertion into high‑security processes.
- **Security processor** – Trusted Platform Module (TPM).

### What is TPM?
- Hardware‑based, tamper‑resistant crypto‑processor.
- Provides hardware security functions; used with BitLocker for best protection.
- Malicious software cannot tamper with TPM security functions.

**Task 5 Answer:**
- TPM stands for → `Trusted Platform Module`

## 💾 BitLocker Drive Encryption
- Data protection feature for lost/stolen/inappropriately decommissioned computers.
- **Best protection** with TPM (version 1.2 or later).
- On systems **without TPM**, BitLocker requires a **removable drive** (e.g., USB flash drive) containing a **startup key**.

**Task 6 Answer:**
- Removable drive contains → `startup key`

## 📸 Volume Shadow Copy (VSS)
- Coordinates creation of **consistent shadow copies** (snapshots/point‑in‑time copies) for backups.
- Stored in `System Volume Information` folder on each protected drive.
- Allows: create restore points, system restore, configure settings, delete restore points.
- **Security concern:** Malware often deletes VSS files to prevent recovery from ransomware (always have offline/off‑site backups).

**Task 7 Answer:**
- VSS stands for → `Volume Shadow Copy`

## 🚨 Living Off the Land
- Attackers use **built‑in Windows tools and utilities** to avoid detection.
- This tactic is called **Living Off the Land** (LOTL).
- Examples: using PowerShell, WMIC, `net` commands, scheduled tasks, etc.

---

## 🔑 Key Takeaways
- **Windows Update** is mandatory for security; can't be ignored indefinitely.
- **Windows Security** is the central hub for all protection settings (antivirus, firewall, SmartScreen, device security).
- **Public** firewall profile is the default for untrusted networks (airports, coffee shops).
- **TPM** provides hardware‑based security for features like BitLocker.
- **BitLocker** without TPM requires a startup key on a removable drive.
- **VSS** (Volume Shadow Copy) is crucial for system restore but is often targeted by malware.
- **Living Off the Land** is a common attacker tactic – monitoring built‑in tool usage is key for detection.
