# 2.5 - [Nessus](https://tryhackme.com/room/nessus)

## 🔍 Overview
- Nessus is a popular **vulnerability scanner** that uses techniques similar to Nmap but presents results in a GUI.
- It doesn't make assumptions (e.g., it won't assume web apps are on port 80).
- Free version (**Nessus Essentials**) is limited but sufficient for learning.
- Paid version offers more features (similar pricing model to Burp Suite).

---

## 🛠️ Installation (Local Kali VM)

**⚠️ Warning:** Do NOT install on THM AttackBox—not enough storage space!

### Step-by-Step Installation

1. **Register** at [Nessus Essentials](https://www.tenable.com/products/nessus/nessus-essentials) → receive **activation code** via email.

2. **Download** the Debian package: `Nessus-#.##.#-debian6_amd64.deb` → save to `/Downloads/`.

3. **Install** the package:
   ```bash
   sudo dpkg -i package_file.deb
   ```

4. **Start the Nessus service:**
   ```bash
   sudo /bin/systemctl start nessusd.service
   ```

5. **Access the web interface:**
   - Open Firefox → `https://localhost:8834/`
   - Accept security risk (Advanced → Accept the Risk and Continue)

6. **Set up the scanner:**
   - Select **Nessus Essentials**
   - Enter the activation code from email

7. **Create credentials:**
   - Fill in username and password (strong password recommended).

8. **Install plugins:**
   - Nessus downloads required plugins (time varies based on internet speed/hardware).
   - If progress bar stalls → insufficient disk space.

9. **Log in** with the account credentials created earlier.

10. **Success!** Nessus is now installed and ready.

## 🧭 Navigation & Scan Types

### UI Navigation
- **"New Scan"** button – launches a scan.
- **"Policies"** menu (side menu) – allows creation of custom templates.
- **"Plugin Rules"** menu – changes plugin properties (hide, change severity).

### Scan Templates (after clicking New Scan)
| Template | Purpose |
|----------|---------|
| **Host Discovery** | Shows simply what hosts are alive. |
| **Basic Network Scan** | Suitable for any host; most useful general scan. |
| **Credentialed Patch Audit** | Authenticates to hosts and enumerates missing updates. |
| **Web Application Tests** | Specifically scans web applications. |

**Task 2 Answers:**
- Button to launch a scan → `New Scan`
- Side menu for custom templates → `Policies`
- Menu to change plugin properties → `Plugin Rules`
- Scan to see live hosts → `Host Discovery`
- Scan suitable for any host → `Basic Network Scan`
- Scan to authenticate and find missing updates → `Credentialed Patch Audit`
- Scan for web applications → `Web Application Tests`

## 📡 Practical: Running a Network Scan

### Scan Configuration
1. Create a **Basic Network Scan** targeting the deployed VM.
2. **BASIC tab**: Set **"Schedule"** to run at a specific time (useful for bandwidth management).
3. **DISCOVERY tab**: Set **Scan Type** to **"Port scan (all ports)"** to cover 1‑65535.
4. **ADVANCED tab**: Change **Scan Type** to **"Scan low bandwidth links"** for slower connections.

### Results
- After scan completes, look in the **"Port scanners"** family for the **"Nmap"** vulnerability to see open ports.
- Apache HTTP Server version reported by Nessus.

**Task 3 Answers:**
- Option under BASIC to set scan time → `Schedule`
- Scan type covering all ports → `Port scan (all ports)`
- Scan type for low bandwidth → `Scan low bandwidth links`
- Vulnerability showing open ports → `Nessus SYN Scanner`
- Apache HTTP Server version → `2.4.41`

## 🌐 Practical: Running a Web Application Scan

### Configuration
- Run a **Web Application Tests** scan on the target.
- **Takes time**—be patient.

### Findings
- **Plugin ID** for HTTP server type/version detection → (check plugin details).
- Authentication page transmitting credentials in cleartext → (e.g., `/admin/login.php` or similar).
- Config backup file extension → `.bak` (common).
- Directory containing example documents (in a PHP directory) → (e.g., `/examples/` or `/docs/`).
- Vulnerability associated with **X-Frame-Options** → **Clickjacking** (missing or misconfigured X-Frame-Options header allows UI redress attacks).

**Task 4 Answers:**
- Plugin ID for HTTP server version → `10107`
- Authentication page with cleartext credentials → `/login.php`
- Config backup file extension → `.bak`
- PHP directory with example documents → `/external/phpids/0.6/docs/examples/`
- Vulnerability related to X-Frame-Options → `Clickjacking`

## 🔑 Key Takeaways
- **Nessus** automates vulnerability scanning with a user‑friendly GUI.
- Installation requires **registration** and **activation code**.
- Multiple **scan templates** for different purposes (network, web app, credential audits).
- Nessus can be **customised** via schedules, port ranges, and bandwidth settings.
- Web application scans reveal misconfigurations, clear‑text authentication, and missing security headers (like X‑Frame‑Options).
