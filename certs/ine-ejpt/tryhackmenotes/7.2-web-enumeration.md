## 🔧 Task 3-5: Gobuster

### What is Gobuster?
- Written in Go – directory/file and subdomain/vhost brute‑forcing tool.

### Installation
```bash
sudo apt install gobuster
```

### Useful Global Flags
| Flag | Long Flag | Description |
|------|-----------|-------------|
| `-t` | `--threads` | Number of concurrent threads (default 10) |
| `-v` | `--verbose` | Verbose output |
| `-z` | `--no-progress` | Don't display progress |
| `-q` | `--quiet` | Don't print banner |
| `-o` | `--output` | Output file |

### "dir" Mode – Directory Brute‑Forcing
```bash
gobuster dir -u http://10.10.10.10 -w /usr/share/wordlists/dirbuster/directory-list-2.3-medium.txt
```

**Useful Flags:**
| Flag | Description |
|------|-------------|
| `-x` | File extensions to search for (e.g., `.html,.php,.txt`) |
| `-c` | Cookies for requests |
| `-k` | Skip TLS certificate verification |
| `-H` | Custom HTTP headers |
| `-s` | Positive status codes |
| `-b` | Negative status codes (blacklist) |

**Example – search for files:**
```bash
gobuster dir -u http://10.10.252.123/myfolder -w /path/to/wordlist -x .html,.css,.js
```

### "dns" Mode – Subdomain Brute‑Forcing
```bash
gobuster dns -d mydomain.thm -w /usr/share/wordlists/SecLists/Discovery/DNS/subdomains-top1million-5000.txt
```

**Useful Flags:**
| Flag | Description |
|------|-------------|
| `-c` | Show CNAME records |
| `-i` | Show IP addresses |
| `-r` | Use custom DNS resolver |

### "vhost" Mode – Virtual Host Brute‑Forcing
```bash
gobuster vhost -u http://example.com -w /path/to/wordlist
```

### Useful Wordlists
**Kali default:**
- `/usr/share/wordlists/dirbuster/directory-list-2.3-*.txt`
- `/usr/share/wordlists/dirb/big.txt`
- `/usr/share/wordlists/dirb/common.txt`
- `/usr/share/wordlists/dirb/small.txt`

**SecLists (install with `sudo apt install seclists`):**
- `/usr/share/seclists/Discovery/DNS/subdomains-top1million-5000.txt`

## 🔍 Task 7-8: WPScan

### What is WPScan?
- WordPress vulnerability scanner – enumerates themes, plugins, users, and vulnerabilities.

### Installation / Update
```bash
sudo apt update && sudo apt install wpscan
wpscan --update
```

### Basic Scan
```bash
wpscan --url http://cmnatics.playground/
```

### Enumeration Flags
| Flag | Description |
|------|-------------|
| `--enumerate t` | Enumerate themes |
| `--enumerate p` | Enumerate plugins |
| `--enumerate u` | Enumerate usernames |
| `--enumerate vp` | Enumerate vulnerable plugins (requires API) |
| `--plugins-detection aggressive` | More aggressive plugin detection |

### Password Brute‑Forcing
```bash
wpscan --url http://cmnatics.playground --passwords /usr/share/wordlists/rockyou.txt --usernames username
```

### Task 8 Knowledge Check
- Theme URL for "twentynineteen" → `http://cmnatics.playground/wp-content/themes/twentynineteen/`
- Argument to enumerate users → `u`
- Other aggressiveness profile → `aggressive`

## 🔎 Task 10-11: Nikto

### What is Nikto?
- Open‑source web server vulnerability scanner.
- Discovers: sensitive files, outdated servers, misconfigurations, CGI scripts.

### Installation
```bash
sudo apt update && sudo apt install nikto
```

### Basic Scan
```bash
nikto -h http://ip_address
```

### Scanning Multiple Ports
```bash
nikto -h 10.10.10.1 -p 80,8000,8080
```

### Scanning from Nmap Output
```bash
nmap -p80 172.16.0.0/24 -oG - | nikto -h -
```

### Useful Flags
| Flag | Description |
|------|-------------|
| `-p` | Ports to scan |
| `-Plugin` | Specify plugin (e.g., `apacheuser`, `cgi`, `robots`) |
| `-Display` | Show extra info (1=redirects, 2=cookies, E=errors) |
| `-Tuning` | Vulnerability categories (0=file upload, 2=misconfig, 3=info disclosure, 4=injection, 8=command exec, 9=SQLi) |
| `-o` | Output file (`.html`, `.txt`) |

### Task 11 Knowledge Check
- Scan ports 80 and 8080 → `-p 80,8080`
- See cookies → `-Display 2`

## 🔑 Key Takeaways
- **Gobuster** – directory, subdomain, and virtual host enumeration.
- **WPScan** – WordPress‑specific enumeration (themes, plugins, users, password brute‑force).
- **Nikto** – general web server vulnerability scanning.
- Always update WPScan database before scanning.
- Add discovered virtual hosts to `/etc/hosts`.
- Use `-k` flag for Gobuster when dealing with self‑signed certificates.

## 🧰 Commands Quick Reference

| Tool | Command |
|------|---------|

| WPScan brute | `wpscan --url http://target --passwords rockyou.txt --usernames user` |
| Nikto basic | `nikto -h http://target` |
| Nikto ports | `nikto -h http://target -p 80,8080` |
| Nikto cookies | `nikto -h http://target -Display 2` |
