# 1.3 - [Introductory Researching](https://tryhackme.com/room/introtoresearch)

## Overview
- **Research is the most important skill** for a hacker – no one knows everything.
- Methodology: Start with a broad question → get initial understanding → drill down into specifics.
- Example: Finding hidden data in a JPEG → search "hiding things inside images" → discover **steganography** → find tool `steghide` → learn to install/use it via `man` and package managers.
- Sources: Google, blogs, Wikipedia, Exploit-DB, NVD, CVE Mitre – **any info can be useful**.

---

## Research Process (Task 2 Examples)
- **Burp Suite mode to manually send/repeat requests?** → `Repeater`
- **Modern Windows login password hash format?** → `NTLM`
- **Automated tasks in Linux called?** → `Cron Jobs`
- **Number base shorthand for binary (base 2)?** → `Base 16` (hexadecimal)
- **Hash starting with `$6$` format (Unix variant)?** → `sha512crypt`

## Vulnerability Searching
- **Key databases:**
  - **Exploit-DB** – contains ready-to-use exploits (Kali has `searchsploit` for offline searching).
  - **NVD** (National Vulnerability Database) – tracks CVEs (Common Vulnerabilities and Exposures).
  - **CVE format**: `CVE-YEAR-IDNUMBER` (e.g., CVE-2020-10385).
- **Process**: Identify software (e.g., FuelCMS) → search Exploit-DB (`searchsploit fuel cms`) → find relevant exploit → note CVE numbers.

**Task 3 Answers:**
- 2020 XSS in WPForms → `CVE-2020-10385`
- 2016 Debian Apache Tomcat Local Privilege Escalation → `CVE-2016-1240`
- First CVE in VLC media player → `CVE-2007-0017`
- 2020 buffer overflow in sudo (actually 2019 CVE) → `CVE-2019-18634`

> *Note: CVEs are assigned when discovered, not when publicised – so release year may differ.*

## `man` Pages (Linux Manual)
- `man <tool>` – shows manual page with syntax, switches, descriptions.
- Example: `man ssh` → shows usage `ssh <user>@<host>`.
- Search within man: `man ssh | grep -i version` to find switches quickly.

**Task 4 Answers:**
- **SCP – copy entire directory?** → `-r`
- **fdisk – list current partitions?** → `-l`
- **nano – make backup when opening file?** → `-B`
- **Netcat – listen mode on port 12345?** → `nc -l -p 12345`

---

## Key Takeaways
- **Research is iterative** – start with a question, follow leads, learn as you go.
- **Exploit-DB** and **searchsploit** are go-to resources for ready-made exploits.
- **CVEs** are standard references – always note them for reporting.
- **`man` pages** are your first stop for tool usage – no internet required.
- Use **any source** – blogs, Wikipedia, official docs – all can be valuable in infosec.
