# 7.3 - [Vulnversity](https://tryhackme.com/room/vulnversity)

## 🔍 Overview
- This room covers active reconnaissance, web app attacks (file upload vulnerability), and privilege escalation.
- Target machine runs a web server on a non‑standard port (3333) with an upload form.
- Process: Nmap scanning → Gobuster directory enumeration → BurpSuite extension fuzzing → PHP reverse shell → SUID privilege escalation.

---

## 🛠️ Task 2: Reconnaissance (Nmap)

### Nmap Flags Reference
| Flag | Description |
|------|-------------|
| `-sV` | Determine service/version info |
| `-p <x>` or `-p-` | Scan specific port or all ports |
| `-Pn` | Disable host discovery |
| `-A` | OS/version detection + scripts + traceroute |
| `-sC` | Default Nmap scripts |
| `-v` | Verbose mode |
| `-sU` | UDP scan |
| `-sS` | SYN scan |

### Scan Commands & Findings

**1. Scan all ports:**
```bash
nmap -p- 10.145.154.135
```
**Answer:** `6` open ports

**2. Service version scan:**
```bash
nmap -sV 10.145.154.135
```
**Answer:** Squid proxy version `4.10`

**3. OS detection:**
```bash
nmap -O 10.145.154.135
```
**Answer:** `Ubuntu`

**4. Web server port:**
```bash
nmap -p- -A 10.145.154.135
```
**Answer:** `3333`

**Task 2 Answers:**
- Number of open ports → `6`
- Squid proxy version → `4.10`
- Ports scanned with `-p-400` → `400`
- Most likely OS → `Ubuntu`
- Web server port → `3333`
- Verbose mode flag → `-v`

## 🔎 Task 3: Directory Enumeration (Gobuster)

### Gobuster Flags
| Flag | Description |
|------|-------------|

| `-w` | Path to wordlist |
| `-U/-P` | Basic Auth credentials |

**Answer:** `/internal/` (upload form page)

**Task 3 Answer:**

## 💥 Task 4: Compromise the Webserver

### Step 1: Extension Fuzzing with BurpSuite
- Intercept upload request with Burp.
- Send to Intruder (Sniper attack type).
- Fuzz filename extension with payloads: `.php`, `.php3`, `.php4`, `.php5`, `.phtml`.

**Task 4.1 Answer:**
- Blocked file type → `.php`

**Task 4.2 Answer:**
- Allowed extension → `.phtml`

### Step 2: PHP Reverse Shell
- Download PHP reverse shell from [PentestMonkey](https://raw.githubusercontent.com/pentestmonkey/php-reverse-shell/master/php-reverse-shell.php).
- Edit `$ip` to your AttackBox IP (`10.145.70.144`).
- Rename to `php-reverse-shell.phtml`.

### Step 3: Start Netcat Listener
```bash
nc -lvnp 1234
```

### Step 4: Upload and Execute
- Upload `php-reverse-shell.phtml` via `/internal/` upload form.
- Navigate to: `http://10.145.154.135:3333/internal/uploads/php-reverse-shell.phtml`
- Reverse shell connects.

**Task 4.3 Answer:**
- Webserver user → `bill`

**Task 4.4 Answer:**
- User flag → `8bd7992fbe8a6ad22a63361004cfcedb`

## 🔑 Task 5: Privilege Escalation (SUID)

### What is SUID?
- SUID (Set User ID) allows a file to run with the permissions of the file owner (often root).
- Example: `/usr/bin/passwd` has SUID to write to `/etc/shadow`.

### Finding SUID Files
```bash
find / -perm -u=s -type f 2>/dev/null
```
**Answer:** `/bin/systemctl` stands out (can be used to escalate privileges)

### Exploiting `/bin/systemctl`
- Systemctl can be used to create and start a service as root.
- Create a malicious service file that executes a reverse shell or adds a user.

**Task 5 Answer:**
- Root flag → `a58ff8579f0a9270368d33a9966c7fd5`

## 🔑 Key Takeaways
- **Nmap:** Always scan all ports (`-p-`) to find non‑standard services.
- **Gobuster:** Use directory enumeration to find hidden upload forms.
- **BurpSuite:** Fuzz file extensions to bypass upload filters.
- **Reverse Shell:** Use `.phtml` extension if `.php` is blocked; edit IP before uploading.
- **SUID:** Search for SUID binaries; `/bin/systemctl` can be abused for privilege escalation.
