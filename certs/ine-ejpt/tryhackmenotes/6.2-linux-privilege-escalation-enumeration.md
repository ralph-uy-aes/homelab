### Network Interfaces
- `ifconfig` – shows network interfaces (legacy).
- `ip addr` – modern equivalent.

**Answer:**

### Listening Ports & Connections
- `netstat -a` – all listening ports and established connections.
- `netstat -at` – TCP only.
- `netstat -au` – UDP only.
- `netstat -l` – listening ports only.
- `netstat -lt` – listening TCP ports.
- `netstat -tpl` – listening ports with service names and PIDs.
- `netstat -ano` – all sockets, numeric addresses, timers.

**Modern alternative:** `ss -tpl` (replaces `netstat`).

### The `find` Command – Useful Options

| Purpose | Command |
|---------|---------|
| Find file by name | `find / -name filename 2>/dev/null` |
| Find directory by name | `find / -type d -name dirname 2>/dev/null` |
| Find files with specific permissions | `find / -type f -perm 0777 2>/dev/null` |
| Find executable files | `find / -perm -a=x 2>/dev/null` |
| Find files owned by a user | `find /home -user frank 2>/dev/null` |
| Find files modified in last 10 days | `find / -mtime -10 2>/dev/null` |
| Find files accessed in last hour | `find / -amin -60 2>/dev/null` |
| Find files larger than 50MB | `find / -size +50M 2>/dev/null` |
| Find world-writable directories | `find / -writable -type d 2>/dev/null` |
| Find SUID binaries | `find / -perm -u=s -type f 2>/dev/null` |
| Find files with "TryHackMe" in name | `find / -name "*TryHackMe*" 2>/dev/null` |

## 🔑 Key Takeaways
- **Enumeration is the most critical phase** – you can't exploit what you don't know exists.
- **Start with system info** – kernel version, OS version, running processes, cron jobs, installed packages.
- **Know your user** – `id`, `sudo -l`, `history`, environment variables.
- **Check the network** – interfaces, listening ports, existing connections.
- **Find hidden files** – always use `ls -la`; hidden files often contain credentials.
- **Use `find` extensively** – search by name, permissions, size, user, date.
- **`2>/dev/null`** – silences permission errors for cleaner output.
- **Build a checklist** – the more you enumerate, the more vectors you'll find.
