# 2.1 - [OhSINT](https://tryhackme.com/room/ohsint)

## Overview
- Challenge room: Extract personal information from a single image file (old Windows XP wallpaper).
- Requires OSINT (Open Source Intelligence) techniques across multiple platforms.
- **Key skills practiced:** EXIF data extraction, social media OSINT, BSSID geolocation, GitHub recon, WordPress analysis, hidden text discovery.

---

## Recon Process

### Step 1: EXIF Data Extraction
- Image: `WindowsXP_1551719014755.jpg`
- Used `exif.tools` online EXIF viewer.
- **Found in metadata:**
  - Copyright value: `OWoodflint`
  - GPS coordinates: `54,17.687778N, 2,15.022104W`

**Commands/Tools:**
```bash
# Online EXIF viewer
https://exif.tools
# Upload image and view metadata
```

### Step 2: Google Search – Username OSINT
- Searched `OWoodflint` → found **Twitter/X account**: `@OWoodflint`
- Twitter bio: "I like taking photos and open source projects."
- **Avatar:** A cat → **Answer 1**

### Step 3: GPS Coordinates Investigation
- Coordinates format: Degrees, Minutes (`54,17.687778N 2,15.022104W`)
- Converted to DMS format and located in Ingleton/Hawes, England area.
- Did not provide a clear city answer → moved on.

### Step 4: BSSID Analysis (Wi-Fi Access Point Mapping)
- Found BSSID on Twitter: `B4:5D:50:AA:86:41`
- BSSID = MAC address of wireless access point (broadcasted to devices, can be mapped).
- Used **wigle.net** – database of mapped Wi-Fi networks.
- Entered BSSID → located in **London** → **Answer 2**
- Also revealed the SSID: `UnileverWiFi` → **Answer 3**

### Step 5: Deeper OSINT – GitHub and WordPress
- Searched `OWoodflint` again → found GitHub user: **OWoodfl1nt**
- Explored `people_finder` repository → found email: `OWoodflint@gmail.com`
- **Answer 4** (personal email) and **Answer 5** (site: GitHub)

### Step 6: WordPress Blog Discovery
- Found WordPress site with 2019 blog post about being in New York.
- **Answer 6** (holiday destination): `New York`

### Step 7: Password Discovery – Hidden Text
- On the WordPress blog, noticed suspicious whitespace.
- **Inspected element** (right-click → Inspect) → found hidden HTML text: `pennYDr0pper.!`
- **Answer 7** (password): `pennYDr0pper.!`

## Key Takeaways
- **EXIF metadata** can reveal copyright usernames and GPS coordinates.
- **Usernames are often reused** across platforms – Google them for social media, GitHub, blogs.
- **BSSIDs (Wi-Fi MAC addresses) can be geolocated** using public databases like wigle.net.
- **Always check HTML source** – hidden/white text is a common CTF trick.
- **GitHub repositories** can contain personal emails and other useful information.
- OSINT is about connecting dots across multiple public sources.
