## 🛠️ System Configuration (`msconfig`)
- Advanced troubleshooting tool for diagnosing startup issues.
- Requires local administrator rights.
- Launch: `msconfig` in Run (`Win + R`).

### Tabs
| Tab | Purpose |
|-----|---------|
| **General** | Boot selection: Normal, Diagnostic, or Selective (load only basic services/devices). |
| **Boot** | Boot options (Safe Mode, boot logging, timeout, default OS). |
| **Services** | Lists all services (running/stopped); enable/disable to troubleshoot. |
| **Startup** | Redirects to Task Manager (Windows 10/11); on Windows Server, use `shell:startup` folder. |
| **Tools** | List of administrative tools with commands; click Launch to run. |

### Advanced System Settings
- Access via **View advanced system settings** (search) → System Properties.
- **Performance** → Settings → Advanced → Virtual memory (page file) – view/modify size.
- **Startup and Recovery** → Settings – configure crash dump type (Automatic, Kernel, Small, Complete, None).

## 🔒 User Account Control (UAC) Settings
- UAC slider has four levels:
  1. **Always notify** – highest; dims screen (Secure Desktop).
  2. **Notify for apps** (default) – only apps, not user changes.
  3. **Notify without dimming** – no screen dim.
  4. **Never notify** – all notifications off (not recommended).
- Launch: `UserAccountControlSettings.exe` (or search "Change User Account Control settings").

**Task 2 Answer:**
- Command to open UAC Settings → `UserAccountControlSettings.exe`

## 🖥️ Computer Management (`compmgmt.msc`)
- Central utility with three sections: **System Tools**, **Storage**, **Services and Applications**.

### System Tools
- **Task Scheduler** – create/manage automated tasks (run at login, schedule, etc.).  
  - View tasks under **Task Scheduler Library**.  
  - Create basic task via right pane.
- **Event Viewer** – view system, security, application logs.  
  - Event types: Information, Warning, Error, Critical, Verbose.  
  - Windows Logs: Application, Security, System, Setup, Forwarded Events.
- **Shared Folders** – view shares (default: `C$`, `ADMIN$`), sessions, open files.
- **Local Users and Groups** – same as `lusrmgr.msc` (from WF1).
- **Performance** – opens Performance Monitor (`perfmon`) for real‑time/log data.
- **Device Manager** – view/configure hardware, drivers.

### Storage
- **Disk Management** – advanced storage tasks: set up drives, extend/shrink partitions, change drive letters.

### Services and Applications
- **Services** – list all services with status, startup type (Automatic, Manual, Disabled), path, etc.
- **WMI Control** – configure Windows Management Instrumentation (WMIC is deprecated; use PowerShell).

## ℹ️ System Information (`msinfo32`)
- Comprehensive system summary: hardware, components, software environment.
- Sections: **System Summary** (OS, processor, RAM, BIOS), **Hardware Resources**, **Components** (display, network, etc.), **Software Environment** (environment variables, network connections).
- Search bar at bottom to filter.

### Environment Variables
- Store OS and program settings (e.g., `%WINDIR%`, `%COMSPEC%`).
- View via `msinfo32` → Software Environment → Environment Variables, or via Control Panel → System → Advanced system settings.

**Task 4 Answers:**
- Command to open System Information → `msinfo32`
- System Name → `THM-WINFUN2`
- Value for `ComSpec` → `%SystemRoot%\system32\cmd.exe` (or `C:\Windows\system32\cmd.exe`)

## 📊 Resource Monitor (`resmon`)
- Real‑time per‑process CPU, memory, disk, and network usage.
- Tabs: **Overview** (summary), **CPU**, **Memory**, **Disk**, **Network**.
- Advanced filtering, process analysis (deadlocks, file locks).
- Launch via `resmon` or from Task Manager → Performance → Open Resource Monitor.

**Task 5 Answer:**
- Command to open Resource Monitor → `resmon`

## 💻 Command Prompt (`cmd`)
- Legacy CLI; many troubleshooting commands.
- **Basic commands:**
  - `hostname` – computer name.
  - `whoami` – current user.
  - `ipconfig` – network settings; `ipconfig /all` for detailed info.
  - `netstat` – network connections and statistics; use `-a`, `-b`, etc.
  - `net` – manage network resources; `net help user` for help on sub‑commands.
- Help: `/?` for most commands; `net help` for net sub‑commands.
- Clear screen: `cls`.

**Task 6 Answers:**
- Full command for Internet Protocol Configuration (in System Configuration Tools tab) → `ipconfig`
- Show detailed info for `ipconfig` → `/all` (i.e., `ipconfig /all`)

## 📝 Registry Editor (`regedit`)
- Central hierarchical database storing system/user/application settings.
- Launch: `regedit` in Run.
- **Warning:** Editing can break system; backup first.
- Five root keys: HKCR, HKCU, HKLM, HKU, HKCC.

**Task 7 Answer:**
- Command to open Registry Editor → `regedit`

---

## 🔑 Key Takeaways
- **msconfig** is the gateway to many system tools; use it to troubleshoot boot issues.
- **UAC** slider controls notification level; adjust wisely.
- **Computer Management** (compmgmt.msc) is a one‑stop shop for task scheduling, event viewing, shares, services, and disk management.
- **Event Viewer** is critical for incident response and system auditing.
- **System Information** (msinfo32) provides a full system snapshot.
- **Resource Monitor** (resmon) gives deep real‑time performance insights.
- **Command Prompt** still offers powerful network and system commands (`ipconfig`, `netstat`, `net`).
- **Registry** stores almost everything; handle with care.
