## 🖥️ Windows Desktop (GUI)

### Components of the Desktop
| Component | Description |
|-----------|-------------|
| **Desktop** | Shortcuts to programs, folders, files; right‑click for context menu (Display settings, Personalize). |
| **Start Menu** | Windows logo → access to apps, utilities, settings, power options, and user account actions. |

## 📂 NTFS (New Technology File System)

### What is NTFS?
- **Journaling file system** – can auto‑repair files/folders using a log file (unlike FAT).
- Supports:
  - Files larger than 4GB
  - Specific permissions on folders/files
  - Folder/file compression
  - Encryption (EFS – Encrypted File System)

### NTFS Permissions
| Permission | Effect on Files | Effect on Folders |
|------------|-----------------|-------------------|
| Full control | Full access | Full access |
| Modify | Read/write/delete | Read/write/delete |
| Read & Execute | Read/execute | List contents + read |
| List folder contents | N/A | List contents only |
| Read | Read only | Read only |
| Write | Write only | Write only |

- View permissions: Right‑click file/folder → Properties → Security tab.

### Alternate Data Streams (ADS)
- File attribute allowing files to contain **more than one data stream** (`$DATA`).
- Windows Explorer doesn't display ADS by default.
- Malware writers use ADS to hide data.
- Legitimate use: downloaded files get identifiers in ADS (mark of the web).

- NTFS stands for → `New Technology File System`

## 👤 User Accounts & Groups

### Account Types
| Type | Permissions |
|------|-------------|
| **Administrator** | Full system control: add/delete users, modify groups, install programs, change system settings. |
| **Standard User** | Limited: only modify own files/folders; cannot install programs or change system settings. |

### Managing Users
- **Other Users** (Settings) → view/add local users.
- **Local User and Group Management** (`lusrmgr.msc`):
  - Run → `lusrmgr.msc` → see `Users` and `Groups` folders.
  - Each group has set permissions; users inherit group permissions.
- User profiles stored in `C:\Users\<username>` (created on first login).
- Default profile folders: Desktop, Documents, Downloads, Music, Pictures.

## 🛡️ User Account Control (UAC)
- Introduced in Windows Vista to reduce malware risk.
- **How it works:** Administrator accounts run with standard privileges by default; when elevated privileges are needed, UAC prompts for confirmation.
- **Shield icon** on a program indicates UAC will prompt for admin credentials.
- UAC **does not apply** to the built‑in Administrator account by default.
- UAC prompts for password when a Standard User tries to run an admin‑level program.

**Task 5 Answer:**
- UAC stands for → `User Account Control`

## ⚙️ Settings vs. Control Panel

| Menu | Purpose |
|------|---------|
| **Settings** | Modern, touch‑friendly interface; primary location for basic system changes (introduced in Windows 8). |
| **Control Panel** | Traditional, more complex settings; access to advanced configurations (Programs and Features, Network adapters, etc.). |

- Both accessible from Start Menu.
- Search from Start Menu to find settings quickly.

**Task 6 Answer:**

## 📁 Windows Folder (`C:\Windows`)
- Contains the Windows operating system.
- System environment variable: `%windir%` (points to Windows directory).
- **System32** – critical system files; **do not delete** anything from this folder.
- Many Windows tools reside in System32.

**Task 7 Answer:**
- System variable for Windows folder → `%windir%`

## 🖥️ Task Manager
- Access: **Ctrl + Shift + Esc** (or right‑click taskbar).
- Simple view shows running apps; **More details** shows:
  - Processes (CPU, memory, disk, network usage)
  - Performance (real‑time graphs)
  - App history
  - Startup programs
  - Users
  - Details
  - Services

**Task 8 Answer:**
- Keyboard shortcut for Task Manager → `Ctrl+Shift+Esc`

---

## 🔑 Key Takeaways
- Windows Desktop components: Start Menu, Taskbar, Notification Area, Search, Task View.
- **NTFS** is the modern file system with permissions, compression, encryption, and journaling.
- **ADS** can hide data; useful for both legitimate and malicious purposes.
- **Administrator vs. Standard User** – always use least privilege; UAC helps enforce this.
- **Settings** is the new Control Panel, but Control Panel still exists for advanced tasks.
- `%windir%` is the environment variable for the Windows folder.
- **Task Manager** (Ctrl+Shift+Esc) is essential for monitoring system performance and processes.
