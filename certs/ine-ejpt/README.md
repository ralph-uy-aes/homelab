# eJPTv2 Certification: An Introductory Overview

## What is the eJPTv2?

The **eLearnSecurity Junior Penetration Tester Version 2 (eJPTv2)** is an entry-level cybersecurity certification designed to validate foundational penetration testing skills. Powered by Pentester Academy's industry-leading lab platform, this certification serves as the ideal first milestone for individuals beginning their journey into cybersecurity and penetration testing.

## Key Features

- **Hands-on, Browser-based Exam**: Unlike traditional multiple-choice tests, the eJPTv2 features a practical, browser-based exam that simulates real-world junior penetration testing tasks using a methodological approach.

- **Unique Testing Experience**: The exam utilizes innovative dynamic and static flagging technology to create a unique experience for each test-taker, preserving exam integrity.

- **Modern Infrastructure**: The exam environment features current operating systems, modern infrastructure, and up-to-date software versions.

## eJPTv2 vs eJPTv1: Key Differences

| Feature | eJPTv2 | eJPTv1 |
|---------|--------|--------|
| Time Limit | 2 days | 3 days |
| Questions | 35 | 20 |
| Labs | Browser-based | Open VPN |
| Difficulty | Novice | Novice |
| Grading | Overall 70% + Individual domain minimums | Overall 70% minimum |

## Learning Domains

The certification covers four main objectives:

1. **Assessment Methodologies** (25%)
2. **Host and Network Penetration Testing** (35%)
3. **Host and Network Auditing** (25%)
4. **Web Application Penetration Testing** (15%)

## Target Audience

The eJPTv2 is designed for:
- Individuals with **little to no experience** in cybersecurity
- Those seeking to validate entry-level penetration testing skills
- Professionals wanting to understand attack methodologies more fully
- Anyone looking to start their red team journey

## Prerequisites

Basic knowledge of:
- Networking fundamentals
- Linux fundamentals
- Windows fundamentals

## Training Materials

The updated **Penetration Testing Student learning path** includes:
- Video tutorials
- Quizzes
- Dozens of interactive labs
- Regular content updates for relevant, hands-on skills

## Certification Details

- **Exam Duration**: 2 days
- **Total Questions**: 35
- **Passing Score**: Minimum 70% overall + individual domain minimums
- **Voucher Validity**: 180 days from purchase

## For Existing eJPTv1 Holders

- eJPTv1 certification remains permanently valid
- eJPTv1 exam will be sunset three months after eJPTv2 release
- Unredeemed eJPTv1 vouchers can be exchanged for eJPTv2 vouchers free of charge
